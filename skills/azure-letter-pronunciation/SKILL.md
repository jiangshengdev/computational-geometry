# 英文字母读音备用方案

本 skill 是两种备用方案的唯一说明入口，不改变项目默认的 `say-as interpret-as="characters"` 字母拼读方式。遵循[配音与字幕制作规则](../../docs/agents/videos/narration.md)及其音色、原速、素材格式与局部处理要求。

## 使用门禁

- 禁止主动或隐式调用。发现字母错读、漏读、粘连或自动评估异常，不构成启用本方案的授权。
- 使用前必须取得用户对具体方法（单词替换或 IPA）及目标字母、句子或片段范围的明确确认。仅要求“修复读音”、仅打开本 skill 或仅确认目标，不等于确认采用某种备用方法；已有明确确认不重复索取。
- 不得自行选择、混用或切换方法；当前方法失败时说明证据，另一方法仍须用户确认。
- 先生成独立试听，不能自动替换正式素材。正式采用须另获用户对具体版本的确认，并原样复用所选 WAV，不用重新合成冒充已确认音频。
- 默认流程中的自动修复授权不覆盖本 skill。字幕、画面和数学符号保持原义；替换只发生在合成输入中。

## 两种方法

### 单词替换

以英文词、字母名称拼写或短语替代合成输入中的目标字母，并明确使用 `en-US` 朗读。例如 B → `bee`、Q → `queue`、W → `double you`。

```xml
<lang xml:lang="en-US">bee</lang>
```

并非全部字母都有常用同音词。下表带 `*` 的是字母名称拼写或拟音候选；W 是短语。候选表不是正确发音保证，尤其 `ay`、`ee` 等拼写仍可能被引擎误读。`are`、`you` 在整句中可能弱读，孤立词通过不能替代整句试听。

### IPA 指定读音

保留字母原文，通过 SSML 的 `phoneme` 指定英文音素：

```xml
<lang xml:lang="en-US"><phoneme alphabet="ipa" ph="biː">B</phoneme></lang>
```

通过 SSML 合成接口提交，不把标签作为普通文本传入。`ph` 不带音标两侧的斜杠；`.` 表示音节边界。支持范围须核对具体语言、音色与当前服务行为；服务接受标签不证明实际音频遵循了全部音素。服务拒绝时保留错误并停止，不去掉音标重试。

## 生成与试听

1. 核对用户已确认的方法与范围，查看目标的独立口播稿、实际 SSML 和音频。不能仅凭自动评估标记认定错读。
2. 检查当前合成实现和调用方，优先复用已支持的入口。现有封装不支持目标输入时明确说明限制；独立试听可调用已安装的 Azure SDK，不擅自修改正式合成链路或安装依赖。
3. 在请求服务前进行 dry-run，检查完整输入、实际音色、语言标记和 SSML。只改变授权目标的读音处理，保持本轮其他文案、音色及语速。
4. 生成独立的 48 kHz、16 bit、单声道 PCM WAV，保留服务原始字节。保存文本、方法、音标或替代词、SSML、音色、音频哈希及真实时间数据。失败保留证据，不伪造词边界。
5. 检查格式、时长和完整解码。同一回复逐段展示版本、完整对照文本及可播放音频。修复句内字母时提供所在完整片段；用户仅要求孤立字母试验时可以逐字母试听，但不能据此声称整句已修复。
6. 区分请求成功、解码通过、实际听辨和正式采用。用户确认正式采用后，才同步所选音频及受影响的口播、字幕时间和时间线，不扩大处理范围。

## 已有证据与限制

2026-10-29 的独立试验使用 `zh-CN-Xiaoxiao:DragonHDFlashLatestNeural`，两种方法各生成 A–Z 共 26 个 WAV。服务接受请求，音频格式及解码检查通过；未获得全部读音正确的用户确认，也未验证实际句子中的修复效果。此证据不代表未来服务版本或其他音色的效果保证，不自动授权复用或重新合成。
