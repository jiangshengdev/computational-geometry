# 文档写作规则

- 目标读者为初中生。以初中数学知识为基础组织讲解；使用新的概念、术语或符号前，先解释其含义，不默认读者掌握高中或大学数学知识。
- 任何证明都必须给出详细、完整的过程，不得跳过步骤。每一步须说明依据；代入、去分母、展开括号、移项、合并同类项及约分等变形必须逐步写出，不得用「显然」「易得」「整理可得」代替推导。
- 证明中涉及除法、约分或分类讨论时，必须说明成立条件，并完整处理相关特殊情况，不得省略会影响结论的分支。
- 不重复其他文章已经承担的讲解或证明。写作前先检查相关文章；需要前置知识时，链接到对应文章，只简短重述本篇所需的结论、公式及适用条件。本篇新增的推理仍须逐步讲清，不得以「不跳步骤」为由重新展开前置文章。
- 本目录及其子目录中的中文正文使用「」作为引号，不使用“”。
- 代码、命令、标识符及需要逐字保留的原文引用保持原样，不因本规则改写。
