# 文档写作规则

- 目标读者为初中生。以初中数学知识为基础组织讲解；使用新的概念、术语或符号前，先解释其含义，不默认读者掌握高中或大学数学知识。
- 代码、命令、标识符及需要逐字保留的原文引用保持原样，不因本规则改写。

编写、修改或审校文章时，读取并遵循 [文档正文写作规则](../docs/agents/docs-site/writing.md)和[文章配图规则](../docs/agents/coding.md#文章配图)。

涉及站点内容或公共界面文字时，遵循 [双语同步发布](README.zh-CN.md#双语同步发布)：中文为原稿，英文为默认展示语言；同一变更同步更新两种语言，并验证构建后的对应页面、链接、旧片段锚点及配图。
