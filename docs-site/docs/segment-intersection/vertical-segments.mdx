A vertical segment passes through intersections at two different heights. Both have the same $x$ coordinate. At which height should this segment sit in the active order?

This is Chapter 7 of the segment-intersection series. It incorporates vertical inputs into [Chapter 6's point-by-point sweep](./same-x-events.mdx): transform all inputs together, apply the existing rules in the new coordinates, then restore the intersection results. The shear topics provide mathematical proofs. Here we state their results and conditions where needed and follow one set of inputs through the process. You need not read the complete topic first.

## Section 1: Where a vertical segment gets stuck {/* #第一节竖直线段卡在哪里 */}

Take three closed segments, whose names denote fixed original identities:

| Input | Endpoints | Range in the original coordinates |
| --- | --- | --- |
| $\teachBlue{V}$ | $(0,0),(0,3)$ | $x=0$, $0\le y\le3$ |
| $\teachOrange{A}$ | $(-1,1),(1,1)$ | $y=1$, $-1\le x\le1$ |
| $\teachViolet{B}$ | $(-1,2),(1,2)$ | $y=2$, $-1\le x\le1$ |

Call the position where $A$ crosses $V$ $P=(0,1)$, and where $B$ crosses $V$ $Q=(0,2)$. Both points lie within their respective closed ranges. $A,B$ lie on distinct horizontal lines and have no common point. Of the three input pairs, only $V,A$ and $V,B$ intersect.

Read Figures 1 and 2 as a numbered pair, retaining that order when they wrap onto separate rows. Each has an original size of 320 × 260 and equal horizontal and vertical units; $O$ is the origin. **All transformed figures here use the demonstration coefficient $s_{\mathrm{vis}}=1/2$ to magnify the shear. It is not the $s$ used below, and horizontal distances in the figures cannot check the sweep calculations.** Both original and demonstration figures are teaching diagrams, not real execution traces. Coordinate tables, formulas, and event tables always use the actual coefficient.

Chapter 6's [reason for updating only the current block](./same-x-events.mdx#第五节为什么只更新当前块) uses this condition: a nonvertical line has only one height at a fixed $x$ coordinate. One nonzero input therefore cannot participate in both a low and a high event in one column.

Here $V$ covers every height from $0$ to $3$ at $x=0$, containing both $P$ and $Q$. Treating it as one position with a single height fails: choosing $1$ loses its participation at $Q$, while choosing $2$ cannot describe its participation at $P$. Assigning an arbitrary slope does not change this fact. We must first make the inputs satisfy the old rules' conditions, then use those rules.

## Section 2: Transform the inputs into a form the sweep can handle {/* #第二节把输入变成可以扫描的样子 */}

Reuse the transformation from [How a shear changes coordinates](./shear/intuition.mdx):

$$
x'=x+sy,\qquad y'=y.
$$

$x,y$ are original coordinates and $x',y'$ are new coordinates. The prime distinguishes coordinates, not input identities. The same positive number $s$, called the shear coefficient, is chosen for this computation. To transform a point, multiply its $y$ coordinate by $s$ and add that to its original $x$ coordinate; leave its height unchanged. We fix the axes and plot the calculated coordinates as new points, without repeating the interpretation of tilted coordinate axes.

**Every endpoint of every input uses the same $s$.** A shared original position therefore undergoes the same transformation: whichever input we compute along, we get the same new position. Different coefficients for different lines would not transform the whole figure uniformly, so the intersection-correspondence result would not apply.

### How the coefficient ensures the old conditions {/* #系数怎样保证旧条件成立 */}

For rational coordinates, follow [Integer scaling and intersection denominators](./shear/denominator.mdx): choose a positive integer common denominator $D$ making every endpoint's $Dx,Dy$ integers. Let $M$ be the maximum of $1$ and the absolute values of these integers. Use the choice established in [Event spacing and the shear coefficient](./shear/order.mdx):

$$
s=\frac{1}{256(M+1)^5}.
$$

This preserves the left-to-right order of endpoints and actual intersections with originally different $x$ coordinates. The topics above derive the denominator bound, fifth power, and constant. Scaling is used only to select the coefficient; [the original coordinates still use the same $s$](./shear/special-cases.mdx#回到原坐标为什么不用再调整系数), without an extra multiplication or division by $D$.

The result in [Equal horizontal coordinates, degenerate inputs, and original coordinates](./shear/special-cases.mdx#同横坐标竖直线段和退化输入) directly checks both input types. Originally different endpoint $x$ coordinates remain different $x'$ coordinates by order preservation. For endpoints with the same $x$ but different heights, the positive coefficient places the lower endpoint left of the higher. Thus **every nonzero input becomes nonvertical, and originally nonvertical inputs do not become vertical**. This supplies the missing condition. Zero-length inputs remain points; the statement does not turn them into nonzero segments.

The main example already has integer endpoints: take $D=1$. Its largest absolute coordinate is $3$, so $M=3$. It meets the same conditions as the topic's [example with largest absolute coordinate 3](./shear/order.mdx#示例最大绝对坐标为-3), so reuse the result calculated there:

$$
s=\frac{1}{262144}.
$$

We retain the letter $s$ below. It always equals this exact fraction, never the demonstration coefficient or a decimal approximation.

| Input identity | Transformed left endpoint | Transformed right endpoint |
| --- | --- | --- |
| $V$ | $(0,0)$ | $(3s,3)$ |
| $A$ | $(-1+s,1)$ | $(1+s,1)$ |
| $B$ | $(-1+2s,2)$ | $(1+2s,2)$ |

For example, the upper endpoint of $V$ has $x'=0+s\times3=3s$, and the left endpoint of $A$ has $x'=-1+s\times1=-1+s$. Each row retains its original endpoint heights. The new horizontal length of $V$ is $3s>0$, while those of $A,B$ are both $2$.

## Section 3: How original events correspond to transformed events {/* #第三节原来的事件怎样对应过去 */}

First confirm that the transformed problem is still the original problem. [Why shearing preserves intersections](./shear/intersection.mdx) proves that one fixed coefficient maps an entire closed segment to the entire closed segment between its transformed endpoints. The transformation can be uniquely undone, so no common points are lost or introduced. This holds for any rational coefficient and **does not depend on order preservation by a small coefficient**.

The main example's two common points therefore become

$$
P'=(0+s\times1,1)=(s,1).
$$

$$
Q'=(0+s\times2,2)=(2s,2).
$$

Their new $x'$ coordinates differ by $2s-s=s>0$. The bottom-to-top pair $P,Q$ in one original column becomes the left-to-right pair $P',Q'$. This is more than renaming points: $V$ reaches height $1$ at $x'=s$, then height $2$ at $x'=2s$. One order position no longer has to represent two heights in one column.

For other inputs, both same-column separation and preservation of order between originally different columns follow from the coefficient result above. Chapter 6's complete event order can therefore be used in new coordinates. Originally coincident positions remain coincident: same-point participants must not be split into separate processing times. The preserved order is that of geometric event positions; endpoint information and input identifiers must still be retained separately.

Collinearity is also preserved by the [line result in the intersection topic](./shear/intersection.mdx). Originally collinear nonzero inputs remain on one line. Distinct lines cannot merge into one because the transformation is uniquely reversible. Chapter 5's collinear groups are therefore organized by lines in the new coordinates, retaining each original identity inside. Point inputs have no unique supporting line and do not join these groups.

Keep a third responsibility separate: **exact rational arithmetic** prevents fractions from being truncated to finite decimals. The invertible, whole-segment-preserving transformation gives intersection correspondence; the chosen coefficient gives event order preservation; fraction arithmetic avoids rounding error. A small coefficient is not itself a reason for exact calculation.

## Section 4: Complete the sweep in the new coordinates {/* #第四节在新坐标里完成扫描 */}

Now sweep the transformed inputs. Heights, slopes, endpoint ranges, candidate intersections, and future comparisons all use $x',y'$. The names $V,A,B$ still refer to the same original inputs and are not renumbered when their order changes.

### Write the new lines and coverage ranges {/* #写出新直线与覆盖范围 */}

For $V$, originally $x=0$, substitution gives $x'=sy$. Since $y'=y$, this is $x'=sy'$. As $s>0$, divide both sides by $s$ to get $y'=x'/s$. The other two heights remain unchanged:

| Input | Height in new coordinates | New slope | Closed range of new $x'$ coordinates |
| --- | --- | --- | --- |
| $V$ | $y'=x'/s$ | $1/s=262144$ | $[0,3s]$ |
| $A$ | $y'=1$ | $0$ | $[-1+s,1+s]$ |
| $B$ | $y'=2$ | $0$ | $[-1+2s,1+2s]$ |

Ranges come from transformed endpoints. A slope states how much new height changes when the new $x'$ coordinate increases by $1$. We cannot use an old slope for originally vertical $V$, or its old range $x=0$ alone to judge a new intersection.

### From the start events to the two intersections {/* #从开始事件走到两个交点 */}

Because $0<s=1/262144<1/2$, we have $2s<1$. The horizontal inputs' left endpoints satisfy $-1+s<-1+2s<0$, so both start before $V$. $A$ is alone when it joins, and $B$ joins above it. These horizontal lines are parallel; no intersection is scheduled.

At $(0,0)$, $V$ joins at height $0$, below $A,B$. The line intersection of new neighbors $V,A$ satisfies $x'/s=1$. Multiplying both sides by $s$ gives $x'=s$, at height $1$. Since $0<s<3s$ and $-1+s<s<1+s$, the candidate is in both closed ranges and strictly right of the current position, so register $P'$. $A$ still separates $V,B$; this start event has not made them direct neighbors.

At $P'$, both $V,A$ have height $1$ and $B$ has height $2$. First report $P'$ for $V,A$, then use [Chapter 3's slope relation on the right](./exact-predicates.mdx#到了交点等高不等于两侧顺序): $A$ has slope $0$, less than $V$'s $1/s$, so the right-side bottom-to-top order becomes $A,V,B$.

Only now do $V,B$ become new neighbors and get checked. Multiplying $x'/s=2$ by $s$ gives $x'=2s$, height $2$. It satisfies $0<2s<3s$ and $-1+2s<2s<1+2s$, so both inputs cover it. Also $2s>s$, placing it strictly after $P'$, so register $Q'$. This uses [Chapter 6's distinct future and coverage checks](./same-x-events.mdx#第七节把同线组的覆盖与报告接回来): actual range membership and still awaiting processing must be checked separately.

At $Q'$, only $V,B$, both at height $2$, participate; $A$ at height $1$ does not. After reporting $Q'$ for $V,B$, order them $B,V$ on the right since $0<1/s$. The full bottom-to-top order is $A,B,V$. New neighbors $A,B$ are parallel and have no new intersection.

Here are all the events. The order column describes the state **after processing the event**, not an arbitrary ordering of equal-height participants at the meeting point.

| New event position | Current action | Bottom-to-top order after processing |
| --- | --- | --- |
| $(-1+s,1)$ | $A$ starts | $A$ |
| $(-1+2s,2)$ | $B$ starts; $A,B$ are parallel | $A,B$ |
| $(0,0)$ | $V$ starts; discover and register $P'$ | $V,A,B$ |
| $P'=(s,1)$ | Report $V,A$; after updating, discover and register $Q'$ | $A,V,B$ |
| $Q'=(2s,2)$ | Report $V,B$; $A,B$ are parallel | $A,B,V$ |
| $(3s,3)$ | $V$ ends | $A,B$ |
| $(1+s,1)$ | $A$ ends | $B$ |
| $(1+2s,2)$ | $B$ ends | Empty |

The last three endpoints really occur in this order: subtracting $s$ from both sides makes $3s<1+s$ equivalent to $2s<1$; and $1+s<1+2s$ follows from $s>0$. No other input passes through these end events, so no results are added. All endpoints and both real intersections have been processed.

This example incorporates transformed inputs into the sweep without reproving neighbor discovery. General inputs still use Chapter 4's [same-point participant collection](./same-point-events.mdx#怎样找齐旧活动参与者), Chapter 5's [coverage-extension checks](./overlapping-segments.mdx#第五节邻居没变覆盖延长也要补检), and Chapter 6's [complete future comparison](./same-x-events.mdx#第六节完整的未来次序怎样接到事件发现). Their nonvertical condition is now satisfied. A collinear group's farthest right endpoint must also use transformed endpoints' $x'$ coordinates, not a mixture with old endpoints' $x$ coordinates.

## Section 5: Return the answer to the original figure {/* #第五节把答案还给原来的图形 */}

The sweep obtained intersections in the new coordinates. Use the [inverse formulas from the shear topic](./shear/intuition.mdx#从新坐标求回原坐标):

$$
x=x'-sy',\qquad y=y'.
$$

For the result $P'=(s,1)$ of $V,A$, substitution gives

$$
x=s-s\times1=s-s=0,\qquad y=1.
$$

This restores $P=(0,1)$. For the result $Q'=(2s,2)$ of $V,B$, likewise obtain

$$
x=2s-s\times2=2s-2s=0,\qquad y=2.
$$

This restores $Q=(0,2)$. The final answer has two results attached to original unordered input pairs: $P$ for $V,A$ and $Q$ for $V,B$; $A,B$ has empty intersection. Do not return two points without input-pair identities, or mistake the new-coordinate $P',Q'$ for answers in the original figure.

### Restore an entire overlap interval as an entire interval {/* #完整重叠区间也要整段还原 */}

Take a separate short example with only $V$ and a new input $\teachEmerald{W}$, whose endpoints are $(0,1),(0,2)$. Neither $A$ nor $B$ is present. The largest absolute endpoint coordinate remains $3$, so the actual coefficient is still $s=1/262144$.

After transformation, $V$ covers $[0,3s]$ and $W$ covers $[s,2s]$, both on $y'=x'/s$. By Chapter 5's rule of [reporting the complete intersection when a new member joins](./overlapping-segments.mdx#第二节新成员加入时就报告完整交集), when $W$ joins at $(s,1)$ it reports, with same-group member $V$, the complete interval from $(s,1)$ to $(2s,2)$. These positions are not two point results: the solid line emphasizes the entire common part.

Restore the lower endpoint: $x=s-s\times1=0,y=1$; restore the upper: $x=2s-s\times2=0,y=2$. By the whole-segment correspondence cited in Section 3, restore the entire segment determined by these boundaries, obtaining the complete overlap interval from $(0,1)$ to $(0,2)$. Keep the input pair $V,W$, without merging identities. Even if another crossing occurs inside, use Chapter 5's classified reporting, without splitting this interval or reporting it again as a point.

### Point inputs still participate only in their own event {/* #点输入仍只参加自己的事件 */}

Take another separate short example with only $V$ and two point inputs $Z_1,Z_2$, each with both endpoints at $P=(0,1)$. There are no $A,B,W$. Use the same actual $s$.

<IntersectionFigures topic="vertical-segments" prefix="vertical" name="points"
  panels={['Figure 5: In the original coordinates, V meets two point inputs Z1, Z2 at the same position. Neither becomes a positive-length segment, and their positions do not separate. The demonstration coefficient is one half.']}

Both endpoints become $(s,1)$ under the same transformation, so each input still has zero length. By Chapter 4's rule that [point inputs participate in only this event](./same-point-events.mdx#第五节零长度输入参与这一次不留到右侧), merge both point identities with nonzero participant $V$ at $P'$. This produces three point-result pairs: $V,Z_1$, $V,Z_2$, and $Z_1,Z_2$. They share a position but have different identities. Each result is restored to $P$ using $x=s-s\times1=0,y=1$.

$Z_1,Z_2$ acquire neither slopes nor later positions in the active order. $V$ continues through this point and remains the only active input afterward. This connects the existing point-participation rule across the transformation; no new sweep mechanism is needed.

The inputs now satisfy the sweep conditions through one uniform coefficient; all decisions use new coordinates; inverse transformation restores points or complete intervals; and original input pairs are retained throughout. The next chapter organizes the complete mixed-input sweep. General correctness and total work remain for Chapters 9 and 10 respectively.
