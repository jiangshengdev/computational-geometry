给你几条线段，让你找出它们相交的地方，你会怎样做？一种直接的方法是：先取两条，检查它们有没有公共部分，再换一对，直到所有不同的两条都检查过。

这个方法容易想到。不过，在寻找更省事的方法之前，我们要先说清楚：**每次检查的对象是什么，又应该留下什么结果？**

这是 Bentley–Ottmann 线段求交系列的第 1 章。本章先建立问题和基准方法；下一章再研究扫描线怎样减少需要关注的线段对。

## 一份输入，有一个身份

一条线段可以用两个端点描述。例如，端点为 $(0,0)$ 和 $(4,0)$ 的线段，是横轴上从 $0$ 到 $4$ 的那一段。

我们讨论的线段**包含两个端点**，这种线段叫作「闭线段」。所以 $(0,0)$ 和 $(4,0)$ 都在线段上。直线会向两端无限延伸，线段却有范围；例如 $(5,0)$ 在这条线段的延长线上，但不在线段上。若需要回顾方程和范围怎样配合表示线段，可以阅读[由两个端点写出直线方程](./line-equation.mdx)。

两个端点也可以相同。端点都是 $(2,0)$ 时，这份输入只包含点 $(2,0)$，长度为 $0$。我们仍然接受这样的输入。

现在给每份输入编一个号：第 $1$ 条、第 $2$ 条、第 $3$ 条……编号用来区分输入，不表示线段的长短或位置。

假设有下面三份输入，图中分别用 $\teachBlue{S_1}$、$\teachOrange{S_2}$、$\teachViolet{S_3}$ 标出它们；下标就是输入编号：

| 输入编号 | 两个端点 |
| --- | --- |
| $1$ | $(0,0)$ 和 $(4,0)$ |
| $2$ | $(0,0)$ 和 $(4,0)$ |
| $3$ | $(4,0)$ 和 $(0,0)$ |

它们占据的几何位置完全相同。第 $3$ 份只是把端点的书写顺序倒过来，没有改变包含哪些点。可是，这仍然是**三份输入**，不能因为画出来重合，就悄悄删成一份。

接下来，我们用「输入对 $1$ 与 $2$」表示取出编号为 $1$、$2$ 的两份输入。它和「输入对 $2$ 与 $1$」是同一对，因为交换检查顺序不会改变公共部分。这叫作「无序输入对」。我们只取两份不同的输入，不检查一份输入与它自身。

## 两条线段的公共部分是什么

两条线段都包含的点，合起来叫作它们的「交集」。没有公共点时，交集就是空的。

先固定一条线段 $\teachBlue{A}$：从 $(0,0)$ 到 $(4,0)$。它包含的点都满足 $y=0$，横坐标从 $0$ 到 $4$，包含两端。下面每次另取一条线段，与 $A$ 单独比较。

配图中用 $\teachOrange{B}$ 标出每次另取的输入，用 $\teachViolet{A\cap B}$ 表示这两份输入的交集；符号 $\cap$ 读作「交」。没有公共点时，交集为空，用 $\varnothing$ 表示。

### 没有公共点：空交集

另一条线段从 $(0,1)$ 到 $(4,1)$。它上面的点都满足 $y=1$，而 $A$ 上面的点都满足 $y=0$。一个点的纵坐标不能既是 $0$ 又是 $1$，因此两条线段没有公共点。

这对输入检查过了，但**不产生求交结果记录**。

### 只有一个公共点：点交集

换成从 $(2,-1)$ 到 $(2,1)$ 的竖直线段。它上面的点都满足 $x=2$。公共点还必须在 $A$ 上，所以纵坐标必须是 $0$。

这两个条件只留下 $(2,0)$。它的横坐标 $2$ 在 $0$ 到 $4$ 之间，纵坐标 $0$ 在 $-1$ 到 $1$ 之间，因此确实同时在两条线段上。交集就是这一个点。

/>

接触端点也算相交。例如，把另一条线段换成从 $(4,0)$ 到 $(6,0)$ 的水平线段：公共点的横坐标既不能超过 $4$，又不能小于 $4$，只能等于 $4$。两条线段都包含这个端点，所以交集是 $(4,0)$。

零长度输入也按同一个定义处理。如果另一份输入只包含点 $(2,0)$，这个点在 $A$ 上，交集就是它；如果另一份输入只包含 $(5,0)$，它不在 $A$ 的范围内，交集为空。两份点输入则只有在位置相同时才有公共点。

### 有一段公共部分：重叠区间

再换成线段 $B$，从 $(2,0)$ 到 $(6,0)$。它和 $A$ 都在横轴上。

一个公共点必须同时满足：

$$
\teachBlue{0}\le x\le\teachBlue{4},\qquad \teachOrange{2}\le x\le\teachOrange{6}.
$$

第二个条件要求 $x$ 至少为 $2$，第一个条件要求 $x$ 至多为 $4$，所以公共点必须满足 $2\le x\le4$。

反过来，任取一个满足 $2\le x\le4$ 的数，它既在 $0$ 到 $4$ 之间，也在 $2$ 到 $6$ 之间。因此，点 $(x,0)$ 同时属于两条线段。

两个方向合起来说明：交集恰好是从 $(2,0)$ 到 $(4,0)$ 的**完整闭区间**，两端也包含在内。它的长度为 $4-2=2$，不是只有一个点。

不能只报告两个端点，因为 $(3,0)$ 等中间的点也属于交集。我们用区间的两个端点来描述整段公共部分，不是说只有这两个点相交。

/>

如果再加入从 $(3,-1)$ 到 $(3,1)$ 的线段 $C$，它分别与 $A$、$B$ 相交于 $(3,0)$。这是另外两对输入的结果。$A$ 与 $B$ 包含哪些点并没有改变，所以它们的交集仍然是从 $(2,0)$ 到 $(4,0)$ 的一个完整区间，不能在 $(3,0)$ 处拆成两条结果。

## 为什么不会出现两段分开的公共部分

上面看到了空、点和非零长度区间。对闭线段来说，这三类已经包含全部可能。

先考虑某条输入长度为 $0$ 的情况。它只有一个点，公共部分只能是这个点或空，不可能有更多点。

再考虑两条长度都不为 $0$ 的线段。如果公共部分没有点，就是空；如果恰好有一个点，就是点交集。剩下要说明的是：**只要有两个不同的公共点，公共部分就一定是一整段。**

把这两个不同的公共点叫作 $P$、$Q$。两个不同的点确定一条直线。两条线段所在的直线都经过 $P$、$Q$，所以它们在同一条直线上。

如果这条直线不竖直，就按横坐标从小到大排列点。在这条直线上，一个横坐标只对应一个点；线段从一个端点连续延伸到另一个端点，中间所有横坐标对应的点都包含在内。若直线竖直，就改用纵坐标排列，理由相同。

沿这个顺序比较两条线段：把它们各自较前的端点中**更靠后**的一个记作 $L$，把各自较后的端点中**更靠前**的一个记作 $R$。

任何公共点都不能在 $L$ 前面，否则它会落在某条线段的起始范围之外；也不能在 $R$ 后面，否则它会越过某条线段的结束范围。因此，所有公共点都只能在 $L$ 到 $R$ 之间。

反过来，$L$ 到 $R$ 之间的每个点都不早于两条线段各自较前的端点，也不晚于各自较后的端点，因而同时属于两条线段。又因为这里已经有两个不同的公共点，$L$ 必定在 $R$ 前面，不会与 $R$ 重合。

所以公共部分恰好是从 $L$ 到 $R$ 的完整非零长度闭区间，中间不可能断开。这样就说明了全部三种可能。本章用它明确结果的形状；怎样根据任意端点算出结果，留到第 3 章展开。

## 结果既要记位置，也要记是哪一对

现在看一个有三条输入的小例子：

| 输入编号 | 两个端点 |
| --- | --- |
| $1$ | $(-1,0)$ 和 $(1,0)$ |
| $2$ | $(0,-1)$ 和 $(0,1)$ |
| $3$ | $(0,0)$ 和 $(0,0)$ |

第 $1$ 条在横轴上，第 $2$ 条在纵轴上，它们的唯一公共点是原点 $(0,0)$：公共点必须同时满足 $x=0$、$y=0$，并且原点在两条线段的端点范围内。第 $3$ 份只包含原点，而原点又同时在前两条线段上。因此结果为：

| 输入对 | 完整交集 |
| --- | --- |
| $1$ 与 $2$ | 点 $(0,0)$ |
| $1$ 与 $3$ | 点 $(0,0)$ |
| $2$ 与 $3$ | 点 $(0,0)$ |

按从左到右、从上到下的顺序，前三幅图分别展示输入 $1$、$2$、$3$，第四幅将它们放在一起。三份输入都包含原点，但记录结果时，仍须像上表那样分别写出三个输入对。菱形仍表示原点输入，不能因为它与两条线段的交点重合就省略这份输入。

这里只有一个几何位置，却有三对相交输入，所以要保留三条结果。如果只写「原点」，就无法知道究竟哪些输入彼此相交。

回到开头的三份重合输入，它们也有三对：$1$ 与 $2$、$1$ 与 $3$、$2$ 与 $3$。由于每份输入包含的点完全相同，每一对的交集都是从 $(0,0)$ 到 $(4,0)$ 的完整区间。几何位置重合没有取消任何一份输入的身份。

因此，我们的目标可以准确写成：**找出原始输入中所有交集非空的无序输入对，为每一对保留一条结果，记录输入对以及它们的完整交集。**

## 怎样把每一对都检查一遍

先用四份输入练习枚举。这里只列要检查的输入对，具体位置暂时不影响枚举。

| 当前取出的输入 | 只与编号更大的输入配对 | 本行检查数 |
| --- | --- | --- |
| $1$ | $1$ 与 $2$、$1$ 与 $3$、$1$ 与 $4$ | $3$ |
| $2$ | $2$ 与 $3$、$2$ 与 $4$ | $2$ |
| $3$ | $3$ 与 $4$ | $1$ |
| $4$ | 没有编号更大的输入 | $0$ |

总共检查 $3+2+1=6$ 对。每取出一对，就求这两份输入的交集：空的略过，非空的按前面的规则记录。

同样的方法也适用于更多输入。下面说明它为什么既不漏对，也不重复。

**为什么不漏？** 任取两份不同输入，其中必定有一个编号小、一个编号大。处理较小编号那一行时，规则要求与所有更大的编号配对，因此一定会检查到这一对。这个理由适用于任意两份不同输入，不依赖它们的位置或是否相交。

**为什么不重复？** 同一对只能出现在较小编号那一行。到了较大编号那一行，规则只允许找更大的编号，不会再回头找较小编号。在较小编号那一行，每个更大编号又只出现一次，因此这一对总共只检查一次。

这也不会把输入与自身配对，因为「编号更大」排除了相同编号。只要每次两线段求交得到的完整交集正确，枚举就会检查到所有相交输入对，并且每对最多留下一个结果。这就是后续算法可以对照的基准方法。

## 一共需要检查多少对

把原始输入的数量记作 $n$。例如，四份输入时 $n=4$。这里数的是输入份数，重合输入仍然各算一份。

先假设 $n\ge2$。为了数清不同输入对的数量，我们暂时允许交换顺序再数一次：先任选第一份输入，有 $n$ 种选择；再选一份与它不同的输入，有 $n-1$ 种选择。每一种第一份的选择都对应 $n-1$ 种第二份的选择，所以总数为

$$
n(n-1).
$$

但这样把同一对数了两次：例如先选 $1$ 再选 $2$，以及先选 $2$ 再选 $1$。每一对不同输入恰好有这两种顺序，没有第三种；而我们只需要其中的一次。因此把刚才的总数除以 $2$，得到

$$
\frac{n(n-1)}{2}.
$$

前面已经证明，逐对检查方法恰好检查每个无序输入对一次，所以这也是它的检查次数。

代入 $n=4$，先算括号里的减法，再做乘除：

$$
\frac{4(4-1)}{2}
=\frac{4\times3}{2}
=\frac{12}{2}
=6,
$$

与表中逐行得到的 $6$ 对一致。

如果没有输入，或只有一份输入，就选不出两份不同的输入，检查次数都是 $0$。公式也分别给出 $0\times(0-1)/2=0$ 和 $1\times(1-1)/2=0$；这两个边界先由「没有可配对对象」确定，不需要把负数解释成选择数量。

输入多起来时，检查数增长得很快：

| 输入数 $n$ | 检查次数 |
| --- | --- |
| $10$ | $10\times9/2=45$ |
| $100$ | $100\times99/2=4950$ |
| $1000$ | $1000\times999/2=499500$ |

即使这些线段全部互不相交，逐对检查方法仍然会检查这么多对，最后却没有任何求交结果。因此，**检查过多少对**和**实际有多少对相交**是两个不同的数量。

另一方面，也确实存在每一对都相交的输入。例如，让 $n$ 份输入都占据同一条非零长度线段，每一对的交集就是那条完整线段。此时需要保留的结果条数也是 $n(n-1)/2$。如果要求逐条列出这些结果，任何方法都不能省去输出它们本身的工作。

还要注意，检查次数不是完整运行时间。一次检查内部要做几何判断和计算，保存结果也需要工作；使用精确分数时，数字越长，算术运算也可能越费力。本章只计算「要检查多少对」，不把一次检查说成固定的实际耗时。完整的工作量分析将在后续章节展开。

## 从基准方法走向扫描线

我们已经有了明确目标：结果按原始输入对组织，每个相交输入对保留一个点或一段完整重叠区间。也有了可靠的基准方法：逐对检查，既不漏对，也不重复，但无论实际相交情况如何，都要检查 $n(n-1)/2$ 对。

接下来的问题是：**当许多线段彼此并不相交时，能不能利用它们的位置关系，少检查一些对，同时仍然找全结果？**
