# 单个 Vercel 项目复用 Rust HTTP 路由

静态前端和 Rust API 选择在同一个 Vercel 项目发布，浏览器通过同域 `/api/*` 请求计算；没有为二者引入独立发布项目。参考官方 Axum 模板接入 `vercel_runtime`，函数入口复用现有 `http::router()`，保留本地后端入口，避免维护两套业务路由。

路由优先交给 Rust API，其次查找静态文件，最后才回退到 SPA，防止页面回退吞掉 API。单项目简化同域接入和一致发布，代价是前后端部署共同绑定该项目及 Rust runtime；若以后需要独立发布或权限隔离，应重新评估这一选择。

依据：2026-10-09 比较单项目与两项目后要求按官方模板改造，并在单项目结果汇报后要求提交，本地提交 `a81a9be`。当前配置见 [api/axum.rs](../../api/axum.rs)、[vercel.json](../../vercel.json)。该记录确认仓库部署结构，不宣称云端构建或路由已经验收。
