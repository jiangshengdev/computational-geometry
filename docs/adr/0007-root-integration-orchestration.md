# 两层独立拥有工具链，根目录编排集成

早期 Rust 测试为了托管真实后端而启动前端测试，前端命令又调用 Cargo，形成混杂的生命周期。为让各层入口具有明确职责，Rust 与前端分别拥有其代码、工具链、构建、测试和运行；跨层集成的一键启动、就绪检查、执行顺序及清理由项目根独立编排。

保留真实端到端验证的便利，但承担根目录编排维护成本；不能把它隐藏在普通 Rust 测试或前端内部流程中。跨层通过明确协议和独立数据夹具协作，后端诊断不得启动前端工具链或导入前端源码。服务使用隔离临时端口，不能占用或复用普通开发服务。
