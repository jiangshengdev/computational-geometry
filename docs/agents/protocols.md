## 接口与协议一致性

- 修改 HTTP 请求或响应、NDJSON 轨迹、Rust 公共 API 或回放 URL 时，检查生产方与消费方的破坏性变更，核对适用 ADR 和已有功能覆盖，并同步更新受影响的接口说明或示例。
- Rust 与 TypeScript 的传输契约必须一致，包括字段名、枚举标签、缺省值以及 `null` 与字段省略的不同语义。遵循本项目现有协议，不为套用其他项目约定统一改名或更换序列化工具。
- 协议变更必须保持精确有理数的无损传递、原始输入对身份、完整重叠区间以及真实 Rust 教学轨迹语义；数值近似仅用于绘图位置，不得由前端复制算法或推测执行状态来补偿协议缺失。
