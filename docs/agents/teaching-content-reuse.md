# 教学内容复用与禁止重复

适用于整个项目的文章、视频、分镜及口播，不限于某一章或专题。

- 绝不重复已有教学内容。规划、编写、修改或审校前，必须通读与当前主题及其前置知识相关的已有文章正文、视频口播稿，并核对对应公式和图示，查清哪些概念、例子、结论与证明已经讲过。标题、README、历史摘要、字数统计和时间线不能代替内容核对；缺少正文或口播时明确说明证据不足，不得凭印象认定内容缺失或已经讲清。
- 已有文章或视频承担的前置讲解，不在后续内容中重新展开、重新推导，也不通过更换例子或措辞重复讲授。需要使用时，链接或明确指向对应材料，仅简短列出当前使用的结论、公式及适用条件，并解释本次新增的联系或推理。
- 同一章的文章与对应视频可以承载同一教学内容，分别服务阅读与观看；这不构成重新讲授前置内容的理由。不得以载体不同为由在后续章节重复已有专题。
- 文章与视频的目标读者均为初中毕业生。直接使用该阶段已经掌握的数学基础，不另设基础知识复习；新的概念、术语、符号及其在算法中的作用仍须先解释含义。
- 新增推理仍须逐步讲清，不能以禁止重复为由省略尚未讲过的必要论证；也不能以完整、独立成篇或不跳步骤为由重讲已有前置证明。
- 提出内容结构、篇幅或视频时长估计前，先依据实际材料说明已有内容的复用位置和本次真正新增的内容，再估算新增讲解及必要观察、理解停顿。不得为了凑足章节、篇幅或时长添加复习、重复解释或重复例题。

## 防重复检查与放行

- 在内容规划、字幕定稿和口播冻结前，按概念、结论、证明或案例逐项对照相关旧材料，列明旧材料的具体位置、本次承接位置及真正新增的内容。记录复用现有分镜或任务记录，不另建平行档案。
- 条件、符号、例子或最终用途发生变化，不代表整段推导都需要重讲。必须拆分已有步骤与新增步骤；已有部分仅引用结论及适用条件，新增部分说明条件变化如何影响结论或用途。
- 缺少对照证据、重复疑点尚未核实，或已确认的重复尚未处理时，不得将受影响内容判为审校通过、冻结或交付。
- 仅优化图形、排版或动画时，不要求重新审校全片；但发现内容重复必须报告具体位置及旧材料依据。修改范围限制不构成忽略问题或判定内容通过的理由。
