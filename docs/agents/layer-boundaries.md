## 前后端职责隔离

- 前端与后端各自负责所属代码、工具链、构建、测试和运行生命周期，禁止将一层的职责放入另一层。
- 禁止后端代码或测试启动前端工具链、导入前端源码；禁止前端代码或测试负责后端构建、服务启动或测试执行。
- 跨层集成由项目根的独立编排入口负责，包括启动、就绪检查、临时端口、执行顺序和清理；不得隐藏在任一层的内部流程中。
- 前后端通过明确的接口、协议或数据格式交互，不直接依赖另一层的内部实现。共享测试输入应使用独立的数据夹具。
- 各层的构建与测试入口保持独立。需要跨层协作的检查应明确归类为集成测试或 E2E，由独立编排入口执行。
- 本规则适用于功能开发、重构、调试、诊断、测试、性能分析及临时脚本，不得以临时用途或执行方便为由绕过。
