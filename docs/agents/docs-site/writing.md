# 文档正文写作规则

适用于 `docs-site/` 及其子目录中文档正文的编写、修改和审校。

- 文章正文、表格和配图中的数值例子优先选用整数，尽可能使坐标、长度、系数、中间计算量和最终结果保持整数。
- 能在不改变教学目标、数学条件和结论的前提下，通过合理选数避免分数时，就不用分数，避免增加无关的通分、约分计算。
- 比例、分数本身的讲解，以及一般公式或证明中必要的分数、分式应保留；不得为了保持整数而改变数学含义、损失精确性或削弱证明的一般性。
- 任何证明都必须给出详细、完整的过程，不得跳过步骤。每一步须说明依据；代入、去分母、展开括号、移项、合并同类项及约分等变形必须逐步写出，不得用「显然」「易得」「整理可得」代替推导。
- 证明中涉及除法、约分或分类讨论时，必须说明成立条件，并完整处理相关特殊情况，不得省略会影响结论的分支。
- 不重复其他文章已经承担的讲解或证明。写作前先检查相关文章；需要前置知识时，链接到对应文章，只简短重述本篇所需的结论、公式及适用条件。本篇新增的推理仍须逐步讲清，不得以「不跳步骤」为由重新展开前置文章。
- `docs-site/` 及其子目录中的中文正文使用「」作为引号，不使用“”。
