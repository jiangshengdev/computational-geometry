# 新视频参考与代表样例

适用于仓库 `videos/` 下的视频工程；同时遵循 [视频工程规则](../../../videos/AGENTS.md) 中贯穿各阶段的约束。

## 新视频的参考继承

- 开始制作前，明确参考视频及其本地提交版本，读取实际组件、配置和相关制作记录。不得仅凭 README 或“已参考”的描述判断完成继承。
- 默认继承参考视频的成熟能力与呈现规范。优先接入仓库内公共基础模块；教学内容、素材及专用图示仍由各集维护。公共能力不得逐集复制，也不得直接导入相邻视频工程。
- 建立逐项对照清单，覆盖：字幕样式、短句切换与静默保留；统一数学排版与中英文间距；图示标签描边及遮挡；页面空间分配；对象配色与当前步骤强调；推导分组、等号对齐及行距；读音消歧；音画同步。
- 每项注明参考实现、新工程对应实现及差异，并区分已接入、已验证和仍待实现；计划中的接入位置不能写成已具备的能力。具体教学对象按新主题映射，不机械复制旧内容。实质偏离须在实施前说明影响并取得确认；旧版共同缺陷和后来新增要求单独记录，不作为必须继承的行为。

## 分镜中的教学对应

- 在现有分镜中，按稳定片段 ID 对应原文结论、必要的口头解释和画面承担的任务；明确首次引入的对象、当前操作、结果出现时机、本页保留内容及思考窗口。利用已有字段表达，不要求重复建立另一份分镜。
- 画面用于展示对象、关系、过程或数量。将正文改写后再套框不自动构成可视化；没有额外解释价值时使用清楚的文字或公式即可。已讲依据与当前推导可以分区呈现，不把避免重复文字误解为一律单栏或删除必要依据。
- 在制作前核对画面重要内容与口播的双向对应，以及案例和一般论证的区别；不等全片完成后才发现新符号未介绍、图示缺少解释或用案例替代证明。文案与配音制作顺序见[配音与字幕](narration.md#内容对应与制作顺序)。

## 代表样例与批量制作

- 批量制作前，先完成足以覆盖上述能力的最小代表样例，包含普通文字、混排公式、分式推导、坐标标签、逐步揭示，以及包含字母和易错读音的实际整句配音。
- 样例须与参考视频逐项核对，并交用户确认后才能扩展到全片。不得以孤立字母试听代替实际整句验证。
- 已确认样例是全片制作的实现与呈现基准。扩展前读取样例的实际组件、调用方和旁白触发时间，复用已有动画能力；逐段将新旁白中的对象与操作映射到对应图示和语义时机，遵循[教学内容呈现](../../../videos/AGENTS.md#教学内容呈现)。不能只继承样式，另加通用逐词脉动，也不能将动态图示改成整段常亮后宣称已继承。既定表现不重新交给用户选择；确需偏离时说明具体依据与影响，再取得确认。
- 核对实际呈现而非只比较组件名称：对象颜色、屏幕上的提示尺寸、透明度与描边变化、描亮方向和节奏、身份文字及收束时机。保留已确认提示圈、菱形及线段提示的相应行为；图示整体缩放不得无意改变提示尺寸，默认色或静态粗线不得覆盖对象色或遮蔽渐进描亮。具体教学对象可以不同，不能据此省略行为核对。
- 沿已确认的教学段落扩展，完成每段的画面、字幕、口播、实际音频和必要检查后再复用到后续内容；已出现的共性偏差先处理，不带着已知缺陷继续批量复制。沿用既有样例确认，不增设逐段人工批准，也不预先制作与实际内容无关的动画模板。
- 整集完成后检查各类页面与时间线状态，特别是镜头衔接、静默、思考窗口和步骤揭示；不得以少数静态页面通过代替整集覆盖。
- 动画检查覆盖语义短语的开始、中间、结束及对象切换，核对提示对象、比较与选定顺序、结果出现时机，以及提示结束后的完整内容保留。同时验证已确认范例未被连带改动；只有高亮元素存在、正文不闪或页末截图通过，都不能证明讲解过程正确。
