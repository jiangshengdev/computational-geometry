# 新视频参考与代表样例

适用于仓库 `videos/` 下的视频工程；同时遵循 [视频工程规则](../../../videos/AGENTS.md) 中贯穿各阶段的约束。

## 新视频的参考继承

1. 开始制作前，从当前请求、有效规格和执行票确定阶段、修改范围及已确认的旧视频基准。定位参考视频的本地提交、具体页面或片段，读取实际页面组合、调用参数、配置、内容数据及对应检查。参考记录说明已确认的具体能力与适用条件；不能只列视频名称、README 或组件导入。
2. 在已有分镜和逐项对照记录中，为本次需要的页型对应旧实现入口、新版承接位置、配置与行为、检查入口及所需观察状态。覆盖字幕样式、短句切换与静默保留，数学排版与中英文间距，图示标签、描边与遮挡，页面空间，对象配色与当前步骤强调，推导分组、等号对齐与行距，以及当前阶段能够核验的读音和音画同步。每项区分已接入、已观察验证、仍待实现和当前阶段不适用。
3. 以完整成熟页面组合和行为作为实现来源，再接入新的教学对象、解释与内容；同时承接使这些行为成立的参数、时序和检查。公共能力沿现有共享层组织，教学内容、素材和专用图示仍由各集维护，不逐集复制公共能力，也不直接导入相邻工程。已有对象的几何关系与已确认呈现均须保留，不能通过改基准或删过程消除差异。
4. 只有实际核对发现旧实现无法承载本次教学任务时，才在当前授权内新增必要实现，并记录能力缺口、适用条件、方案和与基准的差异。主题不同、组件已导入或某个检查通过，都不是重新组合成熟呈现或省略行为的依据。实质偏离仍在实施前按既有要求说明影响并取得确认；旧版共同缺陷、后续新增要求与可接受差异单列，不作为必须继承的行为。
5. 初版提交独立对齐时，交付本阶段版本、以上来源映射、实际产物入口、已有有效检查、未解决项与尚未具备的证据。静态画面阶段的暂定时间须明确身份，不能冒称实测或音画同步；下一阶段继续核对素材与时间数据的版本。制作、独立对齐、修正和复查按 [制作、修复与交接](workflow.md) 执行。

## 分镜中的教学对应

- 在现有分镜中，按稳定片段 ID 对应原文结论、必要的口头解释和画面承担的任务；明确首次引入的对象、当前操作、结果出现时机、本页保留内容及思考窗口。利用已有字段表达，不要求重复建立另一份分镜。
- 画面用于展示对象、关系、过程或数量。将正文改写后再套框不自动构成可视化；没有额外解释价值时使用清楚的文字或公式即可。已讲依据与当前推导可以分区呈现，不把避免重复文字误解为一律单栏或删除必要依据。
- 在制作前核对画面重要内容与口播的双向对应，以及案例和一般论证的区别；不等全片完成后才发现新符号未介绍、图示缺少解释或用案例替代证明。文案与配音制作顺序见[配音与字幕](narration.md#内容对应与制作顺序)。

## 代表样例与批量制作

- 先核对是否已有获确认且能覆盖本次所需能力的旧视频及版本；已有时直接将其作为制作和对照基准，不重复制作同样的代表样例或索取相同批准。执行票已明确沿用旧视频并取消新增样例确认时，遵从该有效调整。
- 确实没有相应已确认基准、且当前授权覆盖代表样例制作时，按本阶段需要完成最小代表样例，并遵循原有样例确认后扩展的要求。文字、混排公式、分式推导、坐标标签、逐步揭示及包含字母和易错读音的实际整句配音，分别在相关阶段核验；画面阶段不因尚未授权配音而停下独立工作，也不以静态结果代替整句试听。不得新增逐页或逐段人工批准。
- 已确认样例是全片制作的实现与呈现基准。扩展前读取样例的实际组件、调用方和旁白触发时间，复用已有动画能力；逐段将新旁白中的对象与操作映射到对应图示和语义时机，遵循[教学内容呈现](../../../videos/AGENTS.md#教学内容呈现)。不能只继承样式，另加通用逐词脉动，也不能将动态图示改成整段常亮后宣称已继承。既定表现不重新交给用户选择；确需偏离时说明具体依据与影响，再取得确认。
- 核对实际呈现而非只比较组件名称：对象颜色、屏幕上的提示尺寸、透明度与描边变化、描亮方向和节奏、身份文字及收束时机。保留已确认提示圈、菱形及线段提示的相应行为；图示整体缩放不得无意改变提示尺寸，默认色或静态粗线不得覆盖对象色或遮蔽渐进描亮。具体教学对象可以不同，不能据此省略行为核对。
- 沿已确认的教学段落，完成当前已授权阶段对本段要求的产物和必要检查，再将已验证的行为复用到后续内容。已明确分阶段制作时，画面阶段完成本阶段规格要求的画面、字幕及其他文稿产物；独立口播稿按对应授权阶段交付，不以尚未授权的口播制作或正式配音作为展开后续段落的前置条件；音频阶段继续落实实际音频、实测时间、字幕切换和语义提示的对应，不以先前画面检查代替音画同步核验。已出现的共性偏差先处理，不带着已知缺陷继续批量复制。沿用既有样例确认，不增设逐段人工批准，也不预先制作与实际内容无关的动画模板。
- 整集完成后检查各类页面与时间线状态，特别是镜头衔接、静默、思考窗口和步骤揭示；不得以少数静态页面通过代替整集覆盖。
- 动画检查覆盖语义短语的开始、中间、结束及对象切换，核对提示对象、比较与选定顺序、结果出现时机，以及提示结束后的完整内容保留。同时验证已确认范例未被连带改动；只有高亮元素存在、正文不闪或页末截图通过，都不能证明讲解过程正确。
