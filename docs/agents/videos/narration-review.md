# 口播文本的分阶段审校流程

适用于首次全文制作或用户明确要求的全文审校；同时遵循[视频工程规则](../../../videos/AGENTS.md)与[配音与字幕制作规则](narration.md)。

本流程仅用于首次全文制作或用户明确要求的全文审校，处理文本及拼音，不以生成、试听或检测音频代替。指定字词或句子的微调不进入本流程，由主代理完成局部查证、修改与必要验证，不重启全文定稿或独立全文盲审。全文任务中，主代理负责交接、版本核对、问题汇总和门禁判断；不得以自己的一次生成及自查替代以下独立工作。仅获检查授权时只提交问题，不自动修改；已获制作或修正授权时在已定范围内推进。

### 问题判定与最小修改

- 通用问题分类、修改范围和结论复用遵循[制作与修复流程](workflow.md#问题判定与修改范围)。口播审校还须给出句内适用条件；仅证明另一种读法或表达成立，不足以证明当前方案错误。
- 区分确定错误、具有具体依据但尚待核实的疑点，以及可接受的不同方案。不得仅凭没有标点或显式停顿，就认定跨词、主谓或数位边界必须连读变调；不得把词典存在其他读音等同于当前语境读法错误。真实疑点仍须查证，但不能为寻求唯一读法，把已可接受的方案变成阻塞项。
- 独立盲审提出重复疑点后，在历史核销阶段按[问题闭环](workflow.md#问题闭环与停止条件)复用仍有效的证据，注明重复并保留原结论；不得提前向盲审者提供旧结论，也不得把撤回的误报或可选读法替换记为缺陷修复。

### 阶段与职责

1. **纯文本定稿**：从已审校字幕派生完整口语稿，保留片段 ID，不加拼音。交给未参与撰写的新子代理逐段对照字幕原始含义，审核语义、数学口语表达、对象指代、断句和空格：中文词组不得拆开，数值与表达式边界不得因口语化成汉字而被误合并。仅验证“汉字之间没有空格”不能判为通过。问题修正后由独立文本审核子代理复核，通过即自动冻结全文及其版本，不再额外要求用户逐句确认。
2. **首次拼音标注**：另建子代理，只接收冻结全文、适用规则和必要的教学语境。按词义查询本地词典，标注多音字；依据明确规则结合整句处理声调、变调和轻声，同时检查应标未标的位置。查证从首次标注开始，不等审核发现疑点才查。允许调整标注对象的切分，但拼接后的文字、标点、字母及顺序必须与冻结文本完全一致。
3. **独立全文盲审**：每轮新建审核子代理，只接收当前完整稿件、冻结纯文本、适用规则和必要语境。逐句检查全部片段的多音字选音、声调、变调、轻声与漏标，不能抽样或只检查最近改动。先提交带版本和覆盖清单的盲审结果；在此之前不得读取历史问题、上一轮结论、标注者或修正者的查证记录。
4. **历史问题核销**：盲审结果提交后，才向本轮审核子代理提供历史问题清单及已有查证依据。逐项判断已修复、仍存在、需查证或有证据撤回，保留盲审原始结果并追加核销结果，不能覆盖旧报告来制造“无问题”。新增发现与历史未解决项合并为本轮问题清单。
5. **独立拼音修正**：另建修正子代理，只提供当前稿件、冻结纯文本、适用规则和本轮问题清单及其依据。核实问题后只改拼音标注，返回逐项处理结果，不能自行宣布审核通过。若发现文字语义或断句歧义，返回纯文本阶段，由该阶段解决、复核并重新冻结，再重新标注和审核；不得在拼音修正中顺手改词或断句。
6. **重新审核与放行**：全文制作或全文审校任务中的修正回到独立全文盲审；同一未改动版本连续两轮由不同的新审核子代理完成全文盲审和历史核销，且无新增问题、无历史遗留问题、无待查证项，才允许标记“全文文本与拼音审校通过”。两轮须顺序执行，后一轮不读取前一轮的结论直到其盲审完成。后续指定词句微调只复核受影响部分，保留未变部分的有效结果，不清零全文审核轮次，不要求重新取得两轮全文通过。审核不完整、失败或中断均不计为通过；不能靠达到固定次数强行放行。

### 上下文隔离与查证

- 各阶段的标注、审核、修正和争议查证使用新的子代理；创建时使用不继承历史的方式（如 `fork_turns="none"`），只传该阶段必需材料，不转发整段主对话。不让同一子代理兼任标注、审核和修正；同一轮先盲审后核销是上述明确允许的两步交接。
- 主代理按 `action-authorization` 为每个子代理限定读写范围、允许动作和结束条件。审核及查证只读，修正仅能写明确授权的稿件；不授予音频生成、Git、发布或继续委派能力。共享工作区不会因新建子代理自动隔离，须明确禁止盲审者主动读取旧报告、历史会话和已有查证结论；必要的项目规则仍须提供，不以隔离为由省略。
- 首选 `macos-dictionary` 查询本地词典，保留词典名称、词头、原始标音和释义，区分精确词条、相关词条、无结果与工具失败。该工具只提供词典证据，语境判断由标注或审核阶段另行完成；不得把相关词条的标音直接移用，也不得把词典原调与口播变调不同直接判为错误。
- 变调和轻声须记录适用规则及句内条件，区分数值、序数、数量短语和词义，不机械按相邻字套用。同词同义同语境的有效依据可复用，但不得以复用绕过盲审隔离；盲审者可自行查询，提交结果后才接收已有查证记录。
- 本地缺少依据或存在争议时，使用 `tavily-search` 定位可靠来源，并核对规范、词典或教学资料的原文与适用语境；搜索摘要或模型生成答案不作为最终依据。网络明确被禁止时不联网。工具不可用或来源仍不足时保留待查证项，不猜测、不自动安装组件、不算通过。
- 审核与修正意见相反，或同一标注反复改回时，新建只读查证子代理，提供具体句子、争议读法和已有来源，由其核对词典及普通话规范并说明理由。禁止凭多数票或最新一次意见裁决；仍无法确定时提交用户，保留阻塞项，不继续无依据地往返修改。

### 记录与完成声明

- 每轮独立全文盲审提交结果后，再核对前次问题清单，保留仍未解决的问题；分类可以辅助解释，不得让问题因改换分类而从总清单消失。问题减少须逐项说明已修复、经证据复核撤回或用户明确排除，不能只报本轮某一类别的数量。每项注明片段 ID、上下文、当前标注、正确读法及判断依据；未核实项单列，不算作通过或确定错误。

- 每次交接绑定完整片段 ID 清单、冻结纯文本版本及当前标注稿版本（如内容哈希），避免不同稿件的检查结果混用。保留各轮审核者、全文覆盖、盲审原始结果、历史核销、修改前后标注、查证来源与理由，以及连续无问题轮次；主代理逐项核对后再放行。
- 正式记录位置遵循项目记录规则，交接中给出实际记录位置。证据中不暴露用户隐私；不得以临时检查产物冒充正式完成记录。中断恢复时先核对版本、未解决问题与已完成轮次，不能仅凭上次口头说“通过”继续。
- 完成时只声明对应版本的文本与拼音已满足上述门禁，不声称绝不会漏错或实际音频读音已验收。流程不自动授权合成、替换音频、渲染、导出、提交或关闭任务。
