# 视频数学排版与教学染色

适用于标题、正文、字幕、依据及图示标签的制作与检查；同时遵循[视频工程规则](../../../videos/AGENTS.md)。页面空间与几何图示见[图示与排版](layout.md)，提示起止及对象切换见[时间线](timeline.md#教学内容与提示的生命周期)。

## 数学显示与中数混排

- 所有画面文字中的数学内容统一使用 LaTeX 排版（由 KaTeX 等数学排版器渲染），包括字幕、标题、副标题、正文与推导、辅助说明、页脚提示、坐标轴与刻度、点名、坐标及图中标注；开场与正文均适用。中文叙述和普通标点保留中文文本排版，不把整句中文强行放入数学模式。
- 字幕中的分数使用适合连续阅读的单行表达，不使用上下堆叠的分式，避免撑高行高、打断阅读。例如将 `\frac{n(n-1)}{2}` 表达为“n(n − 1) 除以 2”；保留分子、分母的整体范围和运算次序，不改变数学含义。中文“除以”等叙述使用普通文本，其中保留的数学表达式仍使用 LaTeX 排版。画面正文与推导公式保留标准分式排版。
- 除上述字幕分数的口语化表达外，数学表达式须作为完整单元进入排版器；字母与上下标、撇号、分式、根式、绝对值及运算符不得拆成数学排版与普通文本混排。原稿中的 Unicode 数学记号须在显示层正确识别并转换，例如将 `X₁` 转为 `X_1`；不得仅转换字母而遗漏下标，也不得依靠 Unicode 上下标字符或手工 CSS 定位代替数学排版。
- 数学排版要求不改变既有颜色规则，也不改变独立口播稿、音频或字幕时间戳。检查须覆盖各类文字位置的实际数学排版，尤其是上下标与中文混排；仅检查文字存在、宽高或溢出不能证明数学排版正确。
- 中数混排通过共享组件保持完整行内排版，组件自身须保留中文与数学内容之间的显式空格，不依赖调用方额外包裹；放入 Flex 或 Grid 时不得让中文、公式和空格成为独立布局项。相关检查须核对浏览器中的实际间距，不能只检查字符串包含空格，同时保持 KaTeX 公式内部结构、正文换行及 SVG 标签行为。

## 教学染色

- 正文、公式及必要图示标签须落实已确认历史视频中的教学染色：区分本页保留的对象身份色与随讲解切换、结束后撤去的局部重点色，按本集实际对象和语义配置。图示有颜色或当前整行有底色、下划线，不能替代正文量、关系及关键词的局部染色；字幕中性要求不得扩大为正文重点也全部中性。只在有对象对应或教学重点的位置使用，不机械要求每行染色，也不全局匹配字母着色。
- 字幕统一使用默认中性色，不添加对象配色或强调色；字幕中的字母、数字、点名与公式同样适用。
- 非重点内容使用所在文本层级的默认中性色，不添加强调色。标题、副标题、辅助说明和页脚提示中的字母、数字、点名与公式，不得仅因匹配数学对象就自动着色。颜色只用于需要观众关注的教学重点或必要的图文对象对应，并局部、克制地使用；对象配色一致不代表该对象每次出现都必须着色。
- 公式染色只能改变颜色，须保留关系符、二元运算符、函数与普通量原有的数学类别及自然间距。不得用外围普通分组将关系符或运算符降为普通原子，例如 `{\color{...}⇔}` 会改变 KaTeX 的关系符间距；优先使用保留数学类别的 `\textcolor{...}{...}` 等写法。裸上下标参数染色时仍须保留 `_`、`^` 所需的参数分组，不能直接拼成 `x_\textcolor...`。不得用额外空格、`\quad` 或 CSS margin 补偿错误的数学类别。
- 新增或修改公式染色逻辑时，按实际受影响范围核对关系符、加减等二元运算符、`min`／`max` 等函数、复合量、上下标及多行公式；在生产排版的实际画面中比较未强调、强调中和强调撤去后的间距、位置与对齐。解析结构核对须保留数学类别和分组差异，不能仅以去色后文字相同判定通过；结构检查也不能替代实际画面检查。不得以静态终态、不溢出或类型检查通过替代强调状态切换的排版核对。
