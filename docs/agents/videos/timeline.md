# 音频与页面时间线

适用于仓库 `videos/` 下的视频工程；同时遵循 [视频工程规则](../../../videos/AGENTS.md) 中贯穿各阶段的约束。

## 完整播放与禁止裁切

- 配音单元须在合成前按[教学步骤](narration.md#按教学步骤独立配音)划分；每条正式配音从首个采样到最后一个采样完整、原速播放，禁止先整页合成再拆段播放。
- 禁止裁切音频文件，也禁止通过 `trimBefore`、`trimAfter`、`startFrom`、`endAt`、偏移读取或其他等效机制只播放源音频的一部分。禁止裁切的范围包括静音，不得以词时间准确、静音边界、检查通过或复用已有素材为例外。
- 镜头、页面和播放组件的生命周期必须容纳整条音频；禁止通过镜头结束、组件卸载或时间窗不足提前截断正在播放的配音。
- 额外的阅读停留安排在完整音频之间；镜头时长和页面切换适配完整音频，不得裁切音频以插入停顿或迁就画面时间窗。后续配音只能在上一条完整播放结束后开始，不得重叠播放。

## 音频与时间线

- 按[音频速率](../../../videos/AGENTS.md#音频速率)保留原始音频；FFmpeg 用于检查解码，ffprobe 用于测量时长。
- 待本次生成的全部目标片段通过检查后，再替换正式素材与时间数据；音频按镜头 ID 命名，保持口语稿、素材和时长数据可对应。
- 时间线以实测音频时长加明确的停顿安排构建；动画和提示映射到镜头实际时长，不让音频迁就旧时间窗。静默镜头和思考窗口须显式维护。
- 按[教学内容呈现](../../../videos/AGENTS.md#教学内容呈现)安排主场景揭示、已讲内容保留、辅助区引用和思考窗口。用实际词时间核对整行完整显示与开口的先后关系；完整的一行允许随后用多句旁白解释，不机械套用统一提前时长。
- 正文需要为右侧内容让位时，将平滑左移与右侧内容的出现时机协调，保留已有内容并避免遮挡；不得通过提前把新内容放进辅助区或改变音频速度来迁就布局。

## 教学内容与提示的生命周期

- 区分已引入的教学对象与短时强调：提示圈、描亮等可在语义短语结束后收束，本页已讲清的点、线、坐标、名称及结论仍须保留，除非当前教学过程明确要求移除。不能把内容是否可见仅绑定到当前旁白的高亮状态。
- 同页切换旁白、进入静默或提示结束时，保持已达到的教学步骤，不因片段局部时间归零、提示重置或没有新提示而退回初始状态。换页和有教学含义的删除单独处理，不以“保留内容”为由提前显示新对象或答案。
- 核对语义提示的开始、中间、结束，以及同页片段交界两侧和静默区间；比较应保留对象和下一步骤的实际状态。短暂消失、提前揭示或遮蔽不能用页末截图正常排除；发现边界问题后检查同类转换的受影响范围，检查深度依据缺陷机制确定，不机械要求每次全片逐帧重跑。

## 页面结束后的停留

- 每个页面结束后必须保留完整画面供观众回看，再清除或切换下一页；开场页和结尾页同样适用。“页面”指清屏或换页前的一整页内容，不是每句旁白或每次公式揭示。
- 停留从该页内容全部显示、动画完成且最后一段旁白结束后开始计算，以三者中最晚的时间为准。普通页至少停留 1 秒，推导密集页至少停留 2 秒；密集页须在分镜或分页数据中显式标记。
- 停留期间保留完整公式、图示和最后一句字幕，不提前清屏、隐藏结论或展示下一页内容。下一页的旁白引入时间不能算作上一页的停留。
- 页末停留单独编排，只顺延后续页面及总时长，不拉伸已有动画、不延迟页内步骤揭示、不改变配音速度。已有思考窗口不得缩短；与页末停留重合时满足两者中较长的时长，不必机械叠加。
- 核对全部页面的停留起止帧、完整内容保留状态和下一页开始时间，不能只检查整片总时长或少数页面。
