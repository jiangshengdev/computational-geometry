# 音频与页面时间线

适用于仓库 `videos/` 下的视频工程；同时遵循 [视频工程规则](../../../videos/AGENTS.md) 中贯穿各阶段的约束。

## 音频与时间线

- 原样保存语音服务返回的音频；FFmpeg 可检查解码，ffprobe 可测量时长，不借这些步骤调整音频速度。
- 待本次生成的全部目标片段通过检查后，再替换正式素材与时间数据；音频按镜头 ID 命名，保持口语稿、素材和时长数据可对应。
- 时间线以实测音频时长加明确的停顿安排构建；动画和提示映射到镜头实际时长，不让音频迁就旧时间窗。静默镜头和思考窗口须显式维护。

## 页面结束后的停留

- 每个页面结束后必须保留完整画面供观众回看，再清除或切换下一页；开场页和结尾页同样适用。“页面”指清屏或换页前的一整页内容，不是每句旁白或每次公式揭示。
- 停留从该页内容全部显示、动画完成且最后一段旁白结束后开始计算，以三者中最晚的时间为准。普通页至少停留 3 秒，推导密集页至少停留 5 秒；密集页须在分镜或分页数据中显式标记。
- 停留期间保留完整公式、图示和最后一句字幕，不提前清屏、隐藏结论或展示下一页内容。下一页的旁白引入时间不能算作上一页的停留。
- 页末停留单独编排，只顺延后续页面及总时长，不拉伸已有动画、不延迟页内步骤揭示、不改变配音速度。已有思考窗口不得缩短；与页末停留重合时满足两者中较长的时长，不必机械叠加。
- 核对全部页面的停留起止帧、完整内容保留状态和下一页开始时间，不能只检查整片总时长或少数页面。
