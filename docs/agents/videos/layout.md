# 视频图示与排版

适用于仓库 `videos/` 下的视频工程；同时遵循 [视频工程规则](../../../videos/AGENTS.md) 中贯穿各阶段的约束。

## 坐标图比例

- 坐标轴必须在正方向端点绘制清晰可见的箭头：常规二维坐标系的 X 轴向右、Y 轴向上，一维数轴沿数值增大方向。轴线或轴名称不能代替箭头；箭头须与轴线相接，且不得被裁切、遮挡或与标签重叠。新增或修改坐标图时必须遵循此要求。
- 所有二维坐标图默认采用等比例坐标：X、Y 轴每个单位占用相同的屏幕长度，使用相同的网格刻度间隔，形成正方形网格。绘图区本身可以是长方形。
- 优先保持现有绘图区大小，通过扩展坐标显示范围适配，不裁掉教学所需的点、线或标注，并检查标签是否重叠、越界。不要分别拉伸两轴来填满画面。
- 若横纵数值跨度悬殊，等比例确实影响教学可读性，允许制作时对具体画面显式指定不等比例并记录原因，同时在画面中清楚标明“不等比例示意”；不得由程序根据数据自动切换。
- 此规则适用于开场及正文所有二维坐标图，一维独立数轴不涉及横纵比例比较。

## 图示信息与覆盖

- 按具体数值案例与一般示意分别核对图中点、线、坐标和标签。具体坐标参与讲解或结论判断时，图示须能清楚对应相应数值；抽象的一般证明不为补齐外观而编造坐标。新增标识仍须遵循音画对应要求，不能仅增加画面而遗漏必要口头解释。
- 排查缺标、配色或比例等共性问题时，盘点实际输入图、结果图及各独立绘制分支，不能只检查共用组件或几张代表截图。按[修改范围](workflow.md#问题判定与修改范围)区分调查覆盖和修改授权；用户限定只改图示时，不顺手改动非图内容。
- 坐标、点名、线段和提示层在实际显示比例下核对可读性、遮挡、颜色对应与尺寸；对重合对象采用不改变真实几何关系的标识。提示圈大小变化不表示点具有面积。动态提示与静态对象分层检查，避免静态描边或标签遮住需要观察的过程。
- 标签须清楚对应所属对象，不能仅以“不重叠、不越界”判定位置合格。在实际画面中同时核对标签与所属对象、邻近对象及其他标签的关系，避免标签远离所属对象、贴近另一点或横跨无关线条而造成误认。例如交点标签不能因向上偏移而看起来属于上方端点。优先在所属对象附近的空白处调整标签方向、间距和对齐；确实无法明确归属时使用引线，不移动真实几何对象。固定偏移或共用标签组件不保证所有案例均合适；新增或修改标签时，核对受影响页面中标签出现及邻近对象变化的实际状态，不能只检查偏移参数或布局边界。

## 重合线段的分图呈现

- 两份输入与交集结果形成三条重合或部分重合的线段时，优先拆分为独立子图，尽可能避免三线叠画。通常将两份输入放在输入图，将交集放在结果图；两份输入仍难以区分时，再把两份输入各自拆成一图。按讲解关系选择上下或并排布局，不以换颜色、加粗、套多层描边或遮盖输入来替代分图。
- 各子图保留相同的坐标方向、单位比例和可比较的坐标范围，清楚标明输入身份与结果归属；整体平移子图只改变版面位置，不改变对象的坐标、长度、端点次序或数学关系。标签、坐标轴及提示层必须随所属子图正确定位；揭示、候选比较、选定边界和结果出现仍按原有讲解顺序推进，不提前显示结果。
- 只有当前讲解确实需要在同一坐标系中直接观察重合关系时，才保留必要的叠画，并说明其教学用途、核对每份输入及结果是否都能辨认。检查须覆盖输入出现、边界选取、结果出现及提示撤去后的实际画面；不能仅凭颜色不同、元素存在或边界不溢出判断三线重叠问题已解决。

## 教学排版与布局检查

页面分区与依据显示遵循[教学呈现](presentation.md)，数学显示、中数混排及颜色遵循[数学排版与教学染色](typography.md)。本节管理页面空间、对齐和布局检查。

- 页面组件及禁用策略遵循[工程与运行环境](../../../videos/AGENTS.md#工程与运行环境)。同一图示不得因正文是否含公式而改变页面坐标；中数混排长句使用统一行组件的换行能力，公式推导保留分组、等号对齐及分式行高。
- 流程框、身份框及其他容器内要求居中的文字，须分别显式设置水平与垂直对齐；水平 `align="center"` 不代表垂直居中。复用 `SvgMathText` 时，将文字锚点设为容器实际中心（矩形为 `x + width / 2`、`y + height / 2`），并设置 `verticalAlign="middle"`；不得把中心坐标传给默认基线对齐，或用字号相关的经验偏移凑出居中。坐标轴、刻度及其他需要基线对齐的标签保留原有语义，不为修复局部框内文字修改共享组件的全局默认值。
- 继承参考页时，核对容器几何、文字锚点和实际生效的对齐参数，不能只复用文字组件而遗漏参考调用方的居中配置。发现框内文字偏移时，盘点同一绘制分支及同类容器的实际调用，按适用语义区分遗漏与正常基线用法；不把所有标签机械改为居中。
- 框内文字的制作自查与独立画面复查，须在实际生产画面中核对文字相对容器的上下、左右留白及与边框、箭头的关系；覆盖受影响的不同文字和容器样式。若揭示、强调或缩放会改变定位，还须核对相应变化状态。元素存在、未越界、无重叠或布局检查通过，不能代替对齐正确的证据；静态定位修复不要求重跑未受影响的动画或全片检查。
- 左侧没有图示或其他内容时，正文块先整体居中，块内保持原有对齐；后续右侧需要展示内容时，再将已有正文整体平滑左移。移动时保留已讲内容，避免遮挡和突跳；左移后的正文仍属于本页主场景，不因此变成辅助区。
- 教学分组与对齐语义显式维护，不从全角空格、中文或标点猜测分组；题目、独立判断和结论与连续等式推导使用各自适合的对齐方式。
- 逐步揭示的未来步骤须预留完整空间，隐藏状态不得改变对齐宽度或行高；含分式的分组须预留足够行高。预留空间不等于让当前正文提前偏在一侧；整体居中与平滑移位须保持块内对齐宽度和行高稳定。
- 布局检查使用生产排版组件和完整页面内容，覆盖开场及正文，检测列宽和正文高度超限。
- 失败页须报告并继续检查其余页面，整体以非零退出码结束；不得通过自动缩字号、拆页或丢弃内容隐藏失败。检查与导出的关系遵循[独立预检与用户导出](operations.md#用户导出)。
