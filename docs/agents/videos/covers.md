# 视频封面

适用于仓库 `videos/` 下的视频工程；同时遵循 [视频工程规则](../../../videos/AGENTS.md) 中贯穿各阶段的约束。

## 封面生成与尺寸

- 视频封面的生成与编辑统一使用 `$node-imagegen` skill，按其入口核对 CLI 参数、依赖和调用方式；不默认使用内置 `image_gen` 或 Python imagegen CLI。模型、质量及其他调用参数遵循该 skill 的当前规则，不在本文重复维护。
- 封面须保留图像生成服务返回的原始尺寸。禁止生成后通过拉伸、缩放、重采样、裁剪或补边强行凑成目标尺寸，包括等比例放大；不得使用 `sips`、ImageMagick 或其他工具绕过此限制。
- 交付前核对实际像素尺寸和比例。若与请求不符，保留原图并如实报告差异，不得将后处理结果宣称为原生生成尺寸或已满足尺寸要求；需要满足目标尺寸时应重新生成。
