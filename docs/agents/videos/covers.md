# 视频封面

适用于仓库 `videos/` 下的视频工程；同时遵循 [视频工程规则](../../../videos/AGENTS.md) 中贯穿各阶段的约束。

## 发布素材路径

- 本项目视频封面沿用各集已有目录规范：原图和完整提示词保存到本集工程的 `assets/covers/`，标题、简介及资源索引保存到 `assets/bilibili-copy.md`。
- 本节路径约定优先于全局生图默认的 `~/Downloads/output/<中文用途分类>/`；不得因全局默认目录而将本项目封面移出单集工程，或要求用户另行确认写入 Downloads。用户明确指定其他路径时，以该次指令为准。
- 文件命名沿用前集的 `bilibili-cover-16x9`、`bilibili-cover-4x3` 等主干，保留生成工具写出的完整提示词，并在发布文案中链接原图、完整提示词及实际尺寸。
- 保留并交付图像生成服务返回的原图，不转换或额外生成 JPG/JPEG 副本；本项目规则优先于全局“自动另存同尺寸 JPG”的要求，发布资源索引不再列出 JPG 副本。

## 封面生成与尺寸

- 视频封面的生成与编辑统一使用 `$node-imagegen` skill，按其入口核对 CLI 参数、依赖和调用方式；不默认使用内置 `image_gen` 或 Python imagegen CLI。模型、质量及其他调用参数遵循该 skill 的当前规则，不在本文重复维护。
- 封面须保留图像生成服务返回的原始尺寸。禁止生成后通过拉伸、缩放、重采样、裁剪或补边强行凑成目标尺寸，包括等比例放大；不得使用 `sips`、ImageMagick 或其他工具绕过此限制。
- 交付前核对实际像素尺寸和比例。若与请求不符，保留原图并如实报告差异，不得将后处理结果宣称为原生生成尺寸或已满足尺寸要求；需要满足目标尺寸时应重新生成。
