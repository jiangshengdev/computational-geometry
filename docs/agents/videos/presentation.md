# 视频教学呈现

适用于教学内容、分镜、画面及口播的制作与审校；同时遵循[视频工程规则](../../../videos/AGENTS.md)。前置知识调查与内容复用遵循[教学内容复用与禁止重复规则](../teaching-content-reuse.md)，字幕与口播的精简及展开程度遵循[信息价值与展开程度](narration.md#信息价值与展开程度)。

## 页面区域职责

制作、修改或审查前，先核对实际页面组件、调用参数和内容来源，分别识别历史依据区、当前讲解区、可视化区和字幕区。主场景包括当前讲解区与可视化区，辅助区用于已讲依据；不得将“主场景”当作正文列的同义词，也不得将图示区当作历史依据区。

以下位置对应采用上方依据、左图右文布局的 BO 教学页；其他页型按实际布局识别职责，不凭共享组件默认值猜测位置，也不强制所有页面采用该布局。

| 区域 | 教学职责 | 内容与保留方式 |
| --- | --- | --- |
| 上方历史依据区 | 提供当前推理实际需要的已讲公式、定义和条件 | 选取必要依据并稳定保留，不罗列全部历史，不重新展开旧证明 |
| 左侧可视化区 | 展示当前对象、关系、数量及变化过程 | 优先用图形表达；保留必要标签、数值和说明，表格等形式按理解收益采用，不堆放另一份正文 |
| 右侧当前讲解区 | 展开本页新结论、公式与推导 | 按教学步骤逐步显示，本页已讲步骤继续保留 |
| 底部字幕区 | 对应当前口播，供连续阅读 | 按语义和时间切换，不承担历史依据或图示职责 |

- 上方的已讲依据与右侧本页推导的累积须分别定位；首次讲解、本页保留与跨页引用遵循下文[内容引入与音画对应](#内容引入与音画对应)，依据显示时机见[历史依据](#历史依据)。内容是否已知按教学阶段判断，不由区域名称决定。
- 左侧文字堆叠的问题须在可视化区内判断：文字是否帮助识别对象、比较数据或理解过程，是否存在更直接有效的图形表达。不得用上方依据或右侧推导的保留要求为左侧重复正文辩护，也不得为消除左侧文字堆叠而删去必要历史依据、收起当前推导或要求用户在两者之间取舍。
- 相同符号、数值或必要公式可以在不同区域承担不同任务。减少重复针对没有新增作用的解释与正文堆叠，不按文字相同直接判为冗余；历史依据保留与当前图形表达须同时满足。

## 内容引入与音画对应

- 首次介绍的对象、条件和结论必须先在主场景呈现并通过旁白讲清楚，不得直接放入辅助区。辅助区只引用前集或本集此前已讲清楚的具体内容；沿用已知结论，不代表本次新选取的对象也已介绍。
- 当前讲解行必须先完整显示，再开始对应口播，包括同一行等式中的结果；不得为了逐词同步而拆碎公式或等读到结果才显示结果。“逐步呈现”指教学行之间的推进。本页新内容逐步累积并保留，换页后才可进入辅助区；不得把尚未讲解的后续内容直接当作已知依据，也不得提前揭示思考题答案。
- 教学内容与旁白必须双向对应：旁白介绍或推导时有对应教学画面；画面首次引入的重要对象、符号、条件、关系和推导有对应口头解释。不能出现长段讲解时主场景空白，也不能出现重要新内容只显示却始终不讲。标题、装饰、已讲内容的保留和后续预告不要求逐字朗读。
- 新增或修改教学画面时，同步核对字幕、独立口播稿和实际音频；不能只补画面、沿用缺少对应解释的旧配音，就宣称修复完成。检查依据是讲解是否完整覆盖画面含义，不是画面比口播早出现几秒；类型、布局或文案检查通过不能替代此项核对。

## 历史依据

- 公式推导、代入及符号判断使用此前结论时，须在当前画面同时列出实际依赖的公式、定义及必要适用条件，包括非零分母、共同比较位置及相减次序；不能只说“代入上一页公式”、列出材料名称或让观众回忆。跨页、跨集的依据沿用当前对象和符号，按[页面区域职责](#页面区域职责)引用与保留。
- 公式依据区须参照已确认旧视频的实际调用和排版，复用 `MathLessonPage` 的 `basis` 与共享 `TeachingReferences`。辅助依据区的标题与公式保持静态，不因当前讲解使用该依据而高亮、变色或闪烁；已显示的依据持续保留。包含本页新对象或新符号的依据，须等主场景完成相应介绍后再显示，不能提前引入或泄露思考题答案。新增或修改时实际观察依据显示前后、同页讲解切换、静默及跨页状态，核对公式、条件、符号、口播与推导对应，并确认依据区没有挤压或遮挡图示、正文及字幕；仅导入共享组件或通过边界检查不等于继承效果已落实。

## 可视化选择

- 制作或修改视频时，须主动逐项寻找可视化机会，尽可能用与讲解对应的图示或过程动画帮助理解对象、关系、过程或数量；不能仅因已有文字或公式就忽略有额外教学价值的可视化。是否添加以理解收益为依据，不要求每页或每句话都有图示；没有额外教学价值时不强求，不为装饰或填满画面制造图示，也不把文字改写后套框当作可视化。可视化须保持数学含义准确，不能用具体示例替代一般证明；已有内容的局部强调动画不等于必须新增图示。
- 位置、相交、顺序、邻接、增删和合并优先用图形及过程变化呈现；数据比较可用表格，代数推导可用公式。在已有分镜中说明观众要看见什么关系或变化，并检查实际呈现是否完成该任务；组件名称、文字套框或布局无溢出不能证明可视化有效。
- 语义动画与高亮遵循[教学内容与提示的生命周期](timeline.md#教学内容与提示的生命周期)，几何图示与页面空间遵循[图示与排版](layout.md)，数学显示与染色遵循[数学排版与教学染色](typography.md)。
