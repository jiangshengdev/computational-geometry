## 组件与库复用

- 前端通用交互控件统一使用 HeroUI 组件及其视觉风格，包括按钮、输入框、链接、提示和浮层等；禁止以原生元素加手写样式或仅调用样式函数替代已有的对应组件。通过组件官方组合 API 渲染原生元素、路由链接，以及复用项目已有的组件封装，属于组件使用。
- 通用界面图标统一复用已引入的 `lucide-react`；库中已有对应图标时，禁止用文本字符、Unicode 符号、emoji、CSS 绘制或手写 SVG 替代。例如增减操作使用 `Plus`、`Minus`，不得将 `+`、`−` 文本作为按钮图标。代码、公式、数据及快捷键说明中具有实际文本含义的符号不属于图标替代。
- 复用检查必须覆盖控件内部的图标和子元素，不能仅因外层使用了 HeroUI 就认定符合要求。纯图标按钮使用组件公开的 `isIconOnly` API，并提供明确的可访问名称；装饰性图标使用 `aria-hidden="true"`，避免重复朗读。
- 组件或库已提供的校验、键盘交互、焦点管理、浮层定位和关闭等行为，必须使用其公开 API，不得另建一套重复实现。业务逻辑通过组件组合和库的扩展接口接入。
- 采用组件默认风格和公开变体，通过布局与必要的领域样式适配页面；不得为模仿既有手写控件而覆盖整套组件样式。替换时保持需求要求的功能、可访问性与页面布局。
- 仅在核实已有组件或库无法满足具体需求后，才允许自定义，并须说明缺失能力与自定义范围。几何算法、领域绘图和专用交互按实际能力判断，不机械替换为通用组件；本规则不授权安装新依赖。
- 完成修改前，必须检查本次涉及的控件及其内部元素是否复用已有组件和图标；发现同一能力仍有文本图标替代或重复手写实现时，在本次授权范围内一并修正，不得以改动小或实现方便为由保留。

## 连续交互与 URL 状态同步

- 滑块拖动、指针移动和键盘长按等连续交互必须区分临时预览与持久提交：过程中更新本地预览，结束后才将最终值写入 URL。禁止在每次 `onChange`、`pointermove` 或重复 `keydown` 中直接调用路由导航、`setSearchParams`、`history.replaceState()` 或 `history.pushState()`。`replace: true` 只控制历史项替换，不限制调用频率，仍会触发浏览器的 `SecurityError`。
- HeroUI Slider 的 `onChange` 用于预览，指针交互通过 `onChangeEnd` 提交；键盘交互须核对库的实际事件语义，不能假定 `onChangeEnd` 只在松键时触发。长按期间保持预览，在松键或失焦时提交最终值，避免每次按键重复事件写 URL。
- 预览须绑定所属页面、案例及 URL 状态；切换案例、浏览器前进后退或其他导航发生后，失效预览不得覆盖新状态。保留刷新、分享与前进后退恢复教学位置的行为，最终值未变化时不重复写入 URL。
- 新增或修改同类页面前，检查其他页面已有的交互保护和相关回归测试；按修改时重构规则复用已有能力或提取共同机制，不得另写一套绕过保护的 URL 同步逻辑。当前 BO 回放的 `BoPages.tsx` 与 `learning/useLearningReplay.tsx` 是已有预览、提交及键盘处理的核查入口，不代表其他页面已自动受保护。
