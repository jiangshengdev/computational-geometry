## 测试范围

- 窄屏适配与 Firefox 兼容性不属于本项目的支持范围。
- 禁止测试外观：不得通过样式断言、尺寸或坐标比较、截图快照等方式锁定颜色、字体、线宽、间距、布局比例、排列、排版、装饰或动画效果等显示偏好。
- 保留功能测试，包括显示设置的切换与记忆、键盘操作、内容可达性、计算结果和回放行为。坐标或尺寸测量仅可用于交互定位、内容可达性或几何正确性等功能验证，不得用于断言外观。
- 混合用例只保留功能检查；纯外观用例及不再使用的辅助代码应删除，不得以回归测试名义重新引入。

## 溢出与滚动验证

- 溢出与滚动测试使用默认字号下的真实有效长内容，禁止通过增大根字号或局部字号制造溢出。
- 涉及计算结果时，使用真实 API 计算产生的结果。
