## 测试范围

- 窄屏适配与 Firefox 兼容性不属于本项目的支持范围。
- 禁止测试外观：不得通过样式断言、尺寸或坐标比较、截图快照等方式锁定颜色、字体、线宽、间距、布局比例、排列、排版、装饰或动画效果等显示偏好。
- 保留功能测试，包括显示设置的切换与记忆、键盘操作、内容可达性、计算结果和回放行为。坐标或尺寸测量仅可用于交互定位、内容可达性或几何正确性等功能验证，不得用于断言外观。
- 混合用例只保留功能检查；纯外观用例及不再使用的辅助代码应删除，不得以回归测试名义重新引入。

## URL 同步交互回归

- 新增或修改带连续交互和 URL 同步的页面时，回归必须覆盖本次涉及的实际页面入口；其他算法页面已有测试不能替代新入口的验证。
- 在 Chromium 与 WebKit 中验证连续拖动和键盘长按：交互期间画面随预览更新且不写入 URL，结束时提交最终位置，没有 `SecurityError`；并验证刷新恢复、浏览器前进后退及切换案例后旧预览失效。检查 URL 或历史 API 写入次数，不能只用少量按钮点击、一次 `End` 跳转或“没有报错”替代提交时机断言。
- 复用或提取共同机制时，覆盖相关调用方的接入，防止某页面仍将连续变化事件直接接到 URL 写入函数。验证范围限定于受影响能力及页面，不据此要求无关全量测试。

## 溢出与滚动验证

- 溢出与滚动测试使用默认字号下的真实有效长内容，禁止通过增大根字号或局部字号制造溢出。
- 涉及计算结果时，使用真实 API 计算产生的结果。
- 修改滚动与 hover／自动定位联动时，在 Chromium 与 WebKit 中覆盖受影响的实际页面：固定教学步骤，让鼠标停在列表行区域，连续执行真实滚轮操作；验证能够离开原位置继续浏览，hover 切换及移出列表不会拉回，步骤本身不变。仅程序化设置 `scrollTop` 或断言高亮变化不能替代该场景。
- 同时验证需要保留的定位入口：画布交互仍能显示对应列表项，步骤切换仍能显示新步骤目标。复用已有用例，只补齐受影响的缺口；不得把诊断用的禁用 hover 对照当作产品修复或唯一通过依据。
