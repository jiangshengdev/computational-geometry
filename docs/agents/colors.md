# 项目颜色规则

- 本项目以 [Tailwind CSS v3 完整色板及项目常用组合](../../shared/colors/README.md)作为文章、视频和界面的颜色参考。完整色值固定为 3.4.17，数据位于 `shared/colors/tailwind-v3.json`，常用明暗组合位于 `shared/colors/project.json`。
- 新增或调整颜色时，默认优先从项目常用组合及 v3 色板选色；允许有明确用途的自定义色，并在相关定义或说明中记录用途。保留已有正文、背景等自定义色，不因引入参考而自动替换。
- 依据背景选择明暗组合，并核对实际显示尺寸下文字、线条和对象之间的可辨认性；色阶名称或来源不代替实际可读性判断。
- 对同一教学内容，文章、视频中的对应对象应采用一致的颜色映射。单个案例的字母与颜色映射不扩展为所有内容的全局规则。
- 沿用各载体已有的颜色使用规则；视频继续遵守[布局与视觉规则](videos/layout.md)，保持局部、克制的教学强调和默认中性色字幕。
- 引入参考本身不授权迁移现有内容。接入共享数据、替换现有色值或升级色板版本时，按当次明确范围实施。
