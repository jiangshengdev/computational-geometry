# 章、篇、集与节的称呼

适用于文章、视频的结构、标题、正文、口播、字幕、制作说明和发布文案。

## 含义与对应关系

- **章**是课程统一的内容单元。同一内容在文章和视频中的章归属、章号保持一致；不得在单篇文章或单集视频内另起一套章号。
- **篇**是独立文章的发布单位，使用“本篇”“上篇／下篇”等称呼。
- **集**是独立视频的发布单位，使用“本集”“上集／下集”等称呼。
- 一章可以分成多篇文章或多集视频；篇与集不要求一一对应，不根据发布数量推导章号。
- **节**是当前篇或集内部的内容单元。文章与视频可按各自讲解节奏划分不同的节，不要求节名、节号或边界跨载体对应。

## 标题与引用

- 每篇文章、每集视频从第一节重新编号，节标题显式写作“第一节：主题标题”等。视频的一节可以包含多个教学页面，后续页面保留各自主题标题，不将页号当节号。
- “上一章／下一章”只指课程章节；当前篇或集内的节间衔接使用“上一节／下一节”。“本章条件”等确实指课程适用范围的说法保留，不机械替换为“本节”。
- 文章之间使用“上篇／下篇”等称呼，视频之间使用“上集／下集”等称呼；不得用“节”代指独立发布的文章或视频。
- 跨文章、跨视频或跨载体引用时，使用具体主题标题，并按需补充章及篇／集定位；不能仅凭相同节号假定内容对应。
- 例如“第 2 章下集”内部可以有“第四节：没有事件，为什么顺序不变”；其中的“第四节”不是课程第四章。结尾确实预告课程后续章节时仍使用“下一章”。

## 应用与核对范围

- 新增内容和后续修改的相关内容遵循本规则；未纳入当前授权范围的既有文章、视频不自动批量改写。
- 当前首次追溯修正限定为 `videos/bentley-ottmann/why-neighbors`；其他既有内容保留，以后修改时再统一。
- 修改称呼时，核对画面标题、正文引用、字幕原稿、独立口播稿、分句映射、实际配音及制作说明。实际音频需改词时，沿用配音制作与验证流程，不只改文字或伪造时间数据；未完成的试听、音画同步和成片验收分别报告。
