# Bentley–Ottmann 视频公共资源

各集独立维护内容、时间线和制作入口，具体命令见各工程 README。

## 颜色

[colors.ts](colors.ts) 从[项目共享色板](../../shared/colors/README.md)读取浅色主题及少量背景色阶，供四集复用。模块只保存颜色引用与案例映射，不依赖具体视频的教学内容，也不复制上游 HEX 色值。

- `intersection-goals`、`pairwise-baseline`：输入 1–4 分别使用蓝、橙、紫、绿，对象及语义提示共用 `inputColors`。
- `sweep-neighbors`：A 蓝、B 橙、C 紫、D 绿，与文章案例一致。
- `why-neighbors`：具体案例沿用 A/C 的颜色；一般证明 U 蓝、V 橙、W 紫，与文章配图一致。端点量采用蓝、橙区分，差值与推导结果采用紫色。
- 局部强调使用琥珀色；配对背景、强调背景从 v3 对应色系的浅色阶选取。

现有页面背景、正文、字幕和其他中性色保持原样；颜色接入不改变布局、逐步显示、提示起止、口播或音频。这里固定使用浅色主题，不增加明暗切换功能。类型和组件检查不代表成片或可见桌面验收。
