## 当前工程与内容

Composition 为 `CompleteSweep`，1920×1080、60 fps，共 34 页、113 个稳定步骤（CS01–CS111，另含 CS24a、CS24b）。字幕是 `src/storyboard.ts` 中的 `captions`，正文、历史依据、文章位置和旧集承接位置与它们放在同一分镜源中。`timeline.ts` 已移除按字幕字数估算的暂定计时，改由 113 条正式 WAV 的实测时长及词时间生成：74,238 帧，即 20 分 37.3 秒。每段引入 30 帧，同页段间停留 0.5 秒，每页末保留最后一句和已揭示内容两秒；这些停顿在完整音频之外编排，不裁切源文件，也不设置答题等待。20～25 分钟只是规格估计，不为凑时长增加复述。

| 步骤       | 教学范围                                                                         |
| ---------- | -------------------------------------------------------------------------------- |
| CS01–CS27  | 七输入、精确系数、统一变换、组与覆盖、十二个初始位置                             |
| CS28–CS45  | D头至A尾：拒绝覆盖外 P、完整区间报告、覆盖延长后登记 P、短成员退出               |

| CS95–CS111 | 七对完整交集逐对还原、一个区间与六对点、两个点位置、十四空对的分组核对、C 无结果 |

`src/example.ts` 保存七份原始输入，以 bigint 分子及公共分母表达实际扫描坐标 `s=1/15116544`，计算所有十三站的活动成员、顺序、覆盖和队列。`scripts/check-content.ts` 独立从原始端点计算全部 21 对完整交集，对照七对非空答案，并核对各站预期状态、同点参与者、唯一新增事件及逆变换。

主图始终是横纵等单位的原坐标图；离散顺序竖列明确不代表几何高度。只有 CS13 使用八分之一的放大剪切示意，并明确禁止将其用于实际计算。覆盖页把 A/B/C 分行辨认，但共用横向刻度；A/B 的已报告完整区间独立保留。固定同线成员与当前活动成员分开，最大覆盖右端 `R_G` 与候选点 R 不混用。结尾用逐对映射表还原扫描结果，不把原坐标点混画进剪切图。

## 端点身份与观众标签

头尾按本片明确约定的扫描角色命名：精确剪切后 `x′` 较小、扫描先遇到的一端为**头／开始**，较大、后遇到的一端为**尾／结束**；不按原图上下或输入数组下标猜测。`endpointIdentities` 从原端点及精确扫描坐标派生身份，不维护另一份手写事件命名表。

V 的原端点为 `(3,-1)`、`(3,2)`，变换后分别是 `(3-s,-1)`、`(3+2s,2)`，横坐标相差 `3s>0`，所以 **Z 位于 V尾**。Z 自己只标为点输入，不赋予两个不同的头尾。同位置显示红色 `V尾` 与粉色 `Z点`，保留两种身份，但只占一个清单位置。六条非零线段提供十二个不同端点位置，Z 与已有 V尾重合，所以初始化仍是十二个位置。

CS24a/CS24b 补充命名定义与 V/Z 的核对；CS25–27 的初始化表逐行列出“输入身份 → 原端点 → 扫描坐标”，按扫描顺序从上到下阅读。后续待处理清单改为最多六项一行的身份标签，按行阅读；当前事件、累计事件表、标题、正文与字幕同步使用输入身份。字母与“头／尾／点”文字保留，颜色不承担唯一辨认责任。扫描中新登记的 P 使用独立的“新增交点 P”标记，既不伪装为端点，也不预先进入初始化表。

E1–E13 只作为工程中的稳定索引和文章对照数据存在，观众页面不显示事件编号。内容检查验证十三身份顺序、所有头尾的精确横坐标关系、V尾/Z合并及字幕无事件编号；页面检查验证初始化十二行且无 P，同位置 V尾/Z 各自的文字和不同颜色。

正式素材是 `public/narration/CS*.wav` 共 113 条，由 Azure 直接返回 48 kHz、16 bit、单声道 PCM。`src/audio-timing.json` 绑定源文件、SHA-256、SSML 指纹、实测时长、原始合成事件和逐段识别评估响应；`src/captions.json` 按当前分句对应生成，字幕保留原有自然标点。整批采用前与写入时均完成格式、完整解码、哈希、文字及时间核验，不依赖暂存路径或再次调用服务。当前正式版本评估覆盖 **113/113，Omission 0、Insertion 0、Mispronunciation 61**，没有缺失或失败的正式评估；发音自动标记不等于实际错读结论。

`Composition.tsx` 使用共享 `NarratedLesson`，每条 WAV 从首个采样完整原速播放，未设置裁切、播放速率或重采样。实测词时间定位普通首句动作，以及 CS33/74 的候选计算、CS38 覆盖延长、CS41 登记、CS61 换序、CS64 变换后候选。字幕在句间停顿保持上一句；同页切换保留上一段末句，换页后等待本页首句。原有字数估算、`readingFrames` 和“尚无配音”画面说明已移除。

实测接入检查定位到共享语义锚点错误：部分服务标点事件为零时长且时间戳为零，不能用作发声结束。`phraseTime` 与 `measuredShotRows` 仅从有实际时长的事件定位动作，不修改原始事件或捏造时间；回归覆盖标点为零的句末、正文测量及完整 WAV 页末停留。
