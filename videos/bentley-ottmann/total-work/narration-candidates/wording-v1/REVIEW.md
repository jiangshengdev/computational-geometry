## 文件与复核入口

`source/` 保存四段独立口播、局部读音、原字幕语义映射、措辞对照与读音查证。`audio/` 保存原始WAV、实际SSML计划、请求状态、原始合成词事件、完整评估响应及机器汇总；评估转换副本已清理。原始批次未删改。

在本集目录执行离线检查：

```sh
pnpm --config.verify-deps-before-run=false run narration:plan --source=narration-candidates/wording-v1/source --shots=TW06,TW21,TW26,TW34 --dry-run
pnpm --config.verify-deps-before-run=false run narration:check-staged --source=narration-candidates/wording-v1/source --shots=TW06,TW21,TW26,TW34 --staging=narration-candidates/wording-v1/audio --decode
```

候选入口必须显式指定 `--source` 和 `--shots`；未指定时原45段计划保持原样。实际合成仍须传入计划SHA、独立输出目录，执行前先 `--dry-run`；已有尝试不能清状态后重发。
