## 呈现约定

镜头 ID `U01`–`U52` 固定，不随分页或后续任务编号变化；每项“字幕”是完整阅读文案，可以按自然短句切换，但不得改写标点。后续独立口播、素材与字幕时间均通过此 ID 对应。

每个编号步骤开始前，主场景先完整显示该行及对应对象，再开始讲解；后续行隐藏并预留尺寸。本页已讲行持续保留，换页后才可引用到辅助区。“已知”只列此前讲清楚的内容，不提前放入答案。字幕保持中性色，数学全部由统一排版器呈现，包括坐标与图中标签；颜色仅用于当前重点和必要对象对应。

二维图两轴等比例、正向有箭头。输入用实心端点，点输入用菱形辨认，点结果用圆点；标记尺寸不代表几何面积。重合对象通过同尺度分栏、编号和轮流强调辨认，不挪动真实坐标。结果栏只画完整交集，坐标轴使用灰色细线。

每页末普通页完整停留至少 3 秒，标记“密集”的页至少 5 秒，从画面、动画与最后一段口播全部完成时起算，保留末句字幕。思考窗口另有明确时长，不播放解释或显示答案。时长待后续原速实测音频确定；12～16 分钟仅是规格估算。

## U-A 开场：三份输入，一个位置

主场景：先用三个同范围小图分别展示输入，再汇入同坐标系。已知：无。普通页。

1. **U01**：显示标题和输入 1 的端点、水平线段，不出现结果表。字幕：先看三份输入。第 1 份从 $(-1,0)$ 到 $(1,0)$，是一条经过原点的水平线段。
2. **U02**：第二栏加入输入 2，保留第一栏。字幕：第 2 份从 $(0,-1)$ 到 $(0,1)$，是一条经过原点的竖直线段。
3. **U03**：第三栏加入输入 3 的两端点记录与原点菱形。字幕：第 3 份的两个端点都是 $(0,0)$，它只包含原点这一个点。这仍然是一份独立输入，菱形只是帮助我们认出它，不表示有面积。
4. **U04**：三份输入同图叠合，三栏身份卡仍可见；主场景只出现问题。字幕：把它们放在一起，公共位置只有原点。求交结果应该记几条？先想一想，我们暂时不揭晓答案。

思考窗口：U04 结束后静默 5 秒，仅保留三份输入和问题；没有结果条数、配对表或暗示答案的页脚。随后切页。

## U-B 闭线段与点输入

主场景：新例子从 $(0,0)$ 到 $(4,0)$，换例时明确清除开场编号；无辅助区。普通页。

1. **U05**：整段与两端点出现，标出“包含端点”。字幕：先把输入说清楚。现在换一个例子：从 $(0,0)$ 到 $(4,0)$ 的线段，包含两端之间所有的点，也包含两个端点。这样的线段叫闭线段。
2. **U06**：加入延长线上的 $(5,0)$，仅用灰色虚线示意延长，不延长输入本身。字幕：线段有范围，直线则向两端无限延伸。点 $(5,0)$ 虽在这条线段的延长线上，却不在线段上。
3. **U07**：新小图显示端点都为 $(2,0)$ 的点输入。字幕：两个端点也可以相同。端点都是 $(2,0)$ 时，输入只包含这一个点，长度为零。我们也接受这样的输入。

## U-C 几何重合，身份仍然不同

主场景：三份端点表，逐栏加入同尺度线段图；没有图示时正文整体居中，加入图示时再平滑移位。已知：U05 闭线段。普通页。

1. **U08**：逐行出现编号 1、2、3；本段重新编号，不沿用开场几何。字幕：给每份输入一个编号，编号只表示身份，不表示长短或位置。这个新例子中，第 1 份和第 2 份的端点都是 $(0,0)$ 与 $(4,0)$。
2. **U09**：加入第三行及其独立图。字幕：第 3 份的端点写成 $(4,0)$ 与 $(0,0)$。书写顺序倒过来，包含的点没有改变，线段本身没有因此获得方向。
3. **U10**：共同位置图出现，三张身份卡保留。字幕：三份输入占据完全相同的位置，但仍然有三个身份，不能因为画出来重合就删成一份。分栏只是分别展示，没有把它们移到不同位置。

## U-D 检查对象是无序输入对

主场景：用编号卡演示取出两份输入；已知：U08–U10 的身份。普通页。

1. **U11**：并排展示“1 与 2”和“2 与 1”，用同一对外框包住。字幕：取出编号 1 和编号 2，叫作输入对 1 与 2。交换检查顺序，公共部分不会改变，所以 2 与 1 是同一对，这叫无序输入对。
2. **U12**：显示“取两份不同输入”，自身配对单独划去。字幕：我们只取两份不同的输入，不检查一份输入与它自身。几何相同的两份输入可以配成一对，同一份输入却不能与自己配对。

## U-E 交集与空交集

主场景：三栏“输入 A／另一份输入／完整交集”，先讲清栏义；已知：U05 闭线段。普通页。

1. **U13**：定义交集，再显示固定输入 $A:(0,0)$ 到 $(4,0)$。字幕：两条线段都包含的点，合起来叫它们的交集。接下来固定线段 A，从 $(0,0)$ 到 $(4,0)$；它上面的点满足 $y=0$，横坐标从 0 到 4，包含两端。
2. **U14**：第二栏显示 $(0,1)$ 到 $(4,1)$，依次显示 $y=0$、$y=1$ 条件。字幕：另一条线段从 $(0,1)$ 到 $(4,1)$，上面的点满足 $y=1$。一个点的纵坐标不能同时等于 0 和 1，所以没有公共点，交集为空。
3. **U15**：结果栏标“空交集”，下方显示“检查一对，不留结果”。字幕：右栏只展示完整交集，灰色细线是坐标轴，不是输入或结果。这一对已经检查过，但空交集不产生求交结果记录。

## U-F 一个公共点：内部交叉

主场景：保留固定 A 的身份与范围，另一份改为竖直线段；已知栏引用 U13。密集页。

1. **U16**：第二栏显示 $(2,-1)$ 到 $(2,1)$，主场景加入 $x=2$。字幕：现在把另一份输入换成从 $(2,-1)$ 到 $(2,1)$ 的竖直线段。它上面的点都满足 $x=2$。
2. **U17**：累积条件 $x=2,y=0$，再在同一教学行显示唯一候选 $(2,0)$。字幕：公共点还必须在线段 A 上，所以纵坐标是 0。两个条件只留下一个候选点 $(2,0)$。
3. **U18**：累积范围核对 $0\le2\le4$、$-1\le0\le1$，结果栏加圆点。字幕：横坐标 2 在 A 的范围内，纵坐标 0 也在竖直线段的范围内。因此它确实同时属于两条线段，交集恰好是点 $(2,0)$。

## U-G 端点接触也算相交

主场景：A 与从 $(4,0)$ 到 $(6,0)$ 的输入分别展示。已知：U05、U13。密集页。

1. **U19**：第二份坐标及完整线段先出现。字幕：另一条线段也可以从 $(4,0)$ 到 $(6,0)$，与 A 只在端点处接触。
2. **U20**：累积 $x\le4$、$x\ge4$、$x=4$，结果栏显示 $(4,0)$。字幕：公共点的横坐标既不能超过 4，又不能小于 4，只能等于 4。两条闭线段都包含这个端点，所以交集是点 $(4,0)$。

## U-H 零长度输入仍按定义判断

主场景：逐个替换第二栏点输入，切换时清楚标明当前例子，旧结论作为本页已讲表格保留。已知：U07、U13。普通页。

1. **U21**：点输入 $(2,0)$，结果栏为同坐标圆点。字幕：如果另一份输入只有点 $(2,0)$，这个点在 A 上，所以交集就是它。
2. **U22**：点输入 $(5,0)$，结果栏为空。字幕：如果只有点 $(5,0)$，它超出了 A 的范围，交集为空。仍在同一条直线上，不等于仍在线段上。
3. **U23**：改为两份点输入，同点与异点分栏；分别用 $(2,0)$ 与 $(2,0)$、$(2,0)$ 与 $(5,0)$。字幕：两份点输入只有在位置相同时才有公共点，位置不同时交集为空。每份输入只有一个点，不可能交出一整段。

## U-I 完整重叠区间：两个方向都要说明

主场景：A 与新输入 B 分栏，然后呈现范围推导。已知栏：U13 的 A。密集页。

1. **U24**：介绍 $B:(2,0)$ 到 $(6,0)$，累积 $0\le x\le4$ 与 $2\le x\le6$。字幕：再换成线段 B，从 $(2,0)$ 到 $(6,0)$。它和 A 都在横轴上。公共点必须同时满足 A 和 B 的横坐标范围。
2. **U25**：加入完整一行 $2\le x\le4$，但结果栏暂不宣称已证“恰好”。字幕：B 要求横坐标至少为 2，A 要求横坐标至多为 4。因此，每个公共点都在 2 到 4 之间，这是第一个方向。
3. **U26**：用范围包含关系说明反方向，结果栏整段亮起。字幕：反过来，任取一个在 2 到 4 之间的数，它既在 0 到 4 之间，也在 2 到 6 之间。因此对应的点 $(x,0)$ 同时属于 A 和 B。
4. **U27**：加入完整区间端点、长度 $4-2=2$，中点 $(3,0)$ 作为区间内点出现。字幕：两个方向合起来，交集恰好是从 $(2,0)$ 到 $(4,0)$ 的完整闭区间，长度是 2。两个端点用来描述整段公共部分，中间的点 $(3,0)$ 也属于交集，不能只报告两个端点。

## U-J 加入第三份输入，不拆原来的区间

主场景：上下对应 A、B，左右对照加入 C 前后；底部只画 A 与 B 的交集。已知栏：U24–U27。普通页。

1. **U28**：主场景介绍 $C:(3,-1)$ 到 $(3,1)$；C 分别叠在 A、B 的独立图上。字幕：现在加入线段 C，从 $(3,-1)$ 到 $(3,1)$。它满足 $x=3$，与 A、B 的公共点都只能是 $(3,0)$；这个点在三条线段各自的范围内。
2. **U29**：结果表逐行显示 A 与 C、B 与 C 的点结果；A 与 B 区间保持连续。字幕：A 与 C、B 与 C 是另外两对输入，它们分别产生点结果。A 与 B 包含哪些点没有改变，所以原来的完整重叠区间也没有改变，不能在 $(3,0)$ 处拆成两条结果。

## U-K 从例子走向一般证明

主场景：先显示问题，下一步骤才给分类证明。已知：U14–U29 各类例子。普通页。

1. **U30**：只有“为什么不会出现两段分开的公共部分？”字幕：这些例子展示了空、点和非零长度区间，但例子本身不是一般证明。为什么两条闭线段不可能交出两段分开的公共部分？

思考窗口：U30 后静默 5 秒，无 P、Q、L、R 或一般证明结论；之后进入下一页。

## U-L 有两个不同公共点，就在同一直线上

主场景：条件分支逐行累积，P、Q 在本页首次介绍。已知：U07 点输入、U13 交集定义。密集页。

1. **U31**：显示“至少一份为点输入”。字幕：先看长度为零的情况。只要一份输入只有一个点，交集只能为空或是这个点，不可能有更多公共点。
2. **U32**：显示“两份长度都不为零”，再依次列空／一个／至少两个的讨论条件。字幕：接下来，两条线段长度都不为零。没有公共点时交集为空，恰好一个公共点时是点交集。剩下只需要说明：有两个不同公共点时会怎样。
3. **U33**：在同线示意图标 P、Q，显式写 $P\ne Q$；不以图代证。字幕：把两个不同的公共点叫作 P 和 Q。两个不同的点确定一条直线。两条线段所在的直线都经过 P 和 Q，所以它们必定在同一条直线上。

## U-M 沿共同直线确定前后顺序

主场景：非竖直示意与竖直示意逐步出现，不引入数值斜率。已知栏：U33。密集页。

1. **U34**：非竖直直线，横坐标方向箭头与端点范围。字幕：如果共同直线不竖直，就按横坐标从小到大排列点。在这条直线上，一个横坐标只对应一个点；线段包含两个端点之间每个横坐标对应的点。
2. **U35**：将共同直线改为不带具体数值坐标标签的通用竖直示意，标注“按纵坐标递增”，用向上箭头表示排序方向；保留两份线段及共同点的对应，不把图形当作证明。字幕：如果共同直线竖直，就改按纵坐标从小到大排列，每个纵坐标也只对应一个点，线段同样包含端点之间全部的点。所以竖直情况没有被排除。

## U-N 确定完整公共部分的两端

主场景：同一有向数轴上用两行投影区间表示同线输入，方向只表示坐标递增。已知栏：U33 两个不同公共点；U34–U35 的前后顺序。密集页。

1. **U36**：强调两份各自较前端点，再显示 L。字幕：沿刚才的顺序，每条线段都有一个较前端点和一个较后端点。在两个较前端点中，选更靠后的一个，记作 L；端点重合时就是同一个位置。
2. **U37**：强调两个较后端点，再显示 R，保留 L 的定义。字幕：在两个较后端点中，选更靠前的一个，记作 R。这里的前后只按坐标顺序比较，不由输入端点的书写顺序决定。
3. **U38**：显示“公共点不能早于 L，也不能晚于 R”。字幕：任何公共点都不能在 L 前面，否则会在某条线段的起始范围之外；也不能在 R 后面，否则会越过某条线段的结束范围。因此，所有公共点都在 L 到 R 之间。

## U-O 反方向与非零长度

主场景：延续上页同一图区间，不改端点位置。已知栏明确引用 U36 的 L、U37 的 R、U38 的必要范围、U33 的 P 与 Q。密集页。

1. **U39**：在 L 与 R 之间选任意点，用两份范围分别验证。字幕：反过来，L 到 R 之间的每个点，都不早于两条线段各自较前的端点，也不晚于各自较后的端点，因此同时属于两条线段。
2. **U40**：显示“已有两个不同公共点，L 在 R 前”。字幕：我们已经知道有 P 和 Q 两个不同的公共点，它们都必须在 L 到 R 之间。如果 L 与 R 重合，就至多容纳一个点；如果顺序颠倒，就没有点。因此 L 必定在 R 前面。
3. **U41**：显示完整闭区间 L 到 R，再回收三类。字幕：公共部分恰好是从 L 到 R 的完整非零长度闭区间，包含两端，中间不能断开。结合前面的情况，闭线段交集只有空、点和非零长度区间三类。怎样从任意端点算出交集，留到第 3 章。

## U-P 回到开场：逐对回答

主场景：原样恢复 U01–U03 的三份身份卡与同图，不换编号和坐标。已知：U11–U12 无序输入对、U13 交集。普通页。

1. **U42**：重新逐份指认三输入，结果表仍隐藏。字幕：回到开场：输入 1 是经过原点的水平线段，输入 2 是经过原点的竖直线段，输入 3 只包含原点。现在请按输入对判断，应该留下哪些结果？

思考窗口：U42 后静默 5 秒，表格内容、答案总数全部隐藏；随后在同页逐行解答。

2. **U43**：仅显示“1 与 2：点 $(0,0)$”。字幕：先看 1 与 2。公共点必须同时满足 $x=0$ 和 $y=0$，而原点在两条线段的端点范围内，所以这一对的完整交集是原点。
3. **U44**：加入“1 与 3：点 $(0,0)$”。字幕：再看 1 与 3。第 3 份只有原点，这个点也在第 1 份输入上，所以这一对的完整交集也是原点。
4. **U45**：加入“2 与 3：点 $(0,0)$”。字幕：最后看 2 与 3。原点也在第 2 份输入上，所以这一对仍然留下一个点结果。三对身份不同，不能因为位置相同而合并。

## U-Q 一个位置不等于一条结果

主场景：完整三行结果表与“一个位置／三条结果”并列。已知：U43–U45。普通页。

1. **U46**：显示开场答案。字幕：这里只有一个相交位置，却有三对相交输入，因此要保留三条结果。如果只写原点，就丢掉了哪些输入彼此相交的信息。
2. **U47**：换回 U08–U10 的重合输入，明确“另一个已讲例子”；先完整重现端点表。字幕：还记得三份重合输入吗？它们都占据从 $(0,0)$ 到 $(4,0)$ 的线段，其中一份只是把端点顺序倒过来。这三份也有三个不同的无序输入对。
3. **U48**：逐行展示 1 与 2、1 与 3、2 与 3 的完整区间，均为 $(0,0)$ 到 $(4,0)$。字幕：每对包含的点完全相同，所以每一对的交集都是从 $(0,0)$ 到 $(4,0)$ 的完整区间。几何重合没有取消任何输入的身份。

## U-R 目标与上下集衔接

主场景：目标分三行累积，随后显示下集问题；已知：U11–U12、U15、U41、U46、U48。普通页。

1. **U49**：显示“原始输入的无序输入对”。字幕：现在可以准确说出目标：找出原始输入中所有交集非空的无序输入对。
2. **U50**：加入“每个相交输入对，一条结果”。字幕：为每一对保留一条结果，同时记录是哪一对输入，以及它们的完整交集。
3. **U51**：加入“一个点／完整非零长度重叠区间”。字幕：这个交集可能是一个点，也可能是一段完整的非零长度重叠区间。空交集不留结果，重叠区间不被第三条线段拆开。
4. **U52**：结尾只出现下集问题。字幕：知道了求什么，下一步是怎样把每一对都检查一遍。下集从四条互不相交的线段出发：没有结果，还要做多少检查？
