## 呈现约定

镜头 ID `D01`–`D40` 固定。每项字幕按自然短句切换，后续口播独立维护并绑定同一 ID。当前教学行先完整显示再讲解，已讲行累积，未来行隐藏且预留空间。所有数学使用统一排版，字幕保持中性色；没有图示时正文整体居中，需要并列图示时才平滑移位。新对象先在主场景讲清楚。

二维图保持等比例与正向轴箭头；输入编号固定，几何位置不随枚举变化。普通页末保留完整画面和末句字幕至少 3 秒，密集页至少 5 秒，从本页所有内容、动画和口播完成后计算。思考窗口不展示答案，不缩短以迁就总时长。8～12 分钟只是规格中的估算，不是时长目标或实测结果。

## D-A 没有交集，还要检查吗？

主场景：同一坐标系逐条加入四条水平闭线段，端点表同步出现。已知：上集的闭线段；本集具体坐标首次介绍。普通页。

1. **D01**：输入 1、2 逐行出现。字幕：这次从四份输入开始。第 1 份从 $(0,0)$ 到 $(2,0)$，第 2 份从 $(0,1)$ 到 $(2,1)$。
2. **D02**：加入输入 3、4，保留全部身份卡。字幕：第 3 份从 $(0,2)$ 到 $(2,2)$，第 4 份从 $(0,3)$ 到 $(2,3)$。四条线段在不同高度，横坐标范围都是 0 到 2。
3. **D03**：主场景显示四个不同纵坐标，尚不显示六对枚举表。字幕：每条线段上的纵坐标各不相同，一个点不可能同时处在两个高度。因此这四条线段两两都不相交。
4. **D04**：显示问题“没有交集，逐对检查方法还要检查多少对？”字幕：结果显然是空的。如果使用逐对检查的方法，还要逐对检查吗？一共要检查多少对？先想一想。

思考窗口：D04 后静默 5 秒；不出现六对清单、计数公式或答案。“结果为空”是题目已知条件，可以保留。

## D-B 简短回顾结果定义

主场景：两行回顾后给出基准方法；已知明确引用上集 U49–U51。普通页。

1. **D05**：显示“原始输入无序对 → 完整交集”。字幕：上集已经明确：结果按原始输入的无序对组织。每个相交输入对保留一个点或一段完整重叠区间，并记录输入对的身份。
2. **D06**：显示“取一对 → 求完整交集 → 空的略过，非空的记录”。字幕：基准方法就是把每一对不同输入取出来，求它们的完整交集。空的略过，非空的留下结果。接下来先解决怎样枚举，不展开一般两线段求交的计算。

## D-C 只找更大编号

主场景：原四输入图与配对表并列，按行累积，不移动输入。已知：D01–D03、上集 U11–U12。密集页。

1. **D07**：显示规则及第 1 行的第一对。字幕：从编号小的输入开始，每次只与编号更大的输入配对。先取输入 1，与输入 2 配对。
2. **D08**：第 1 行加入 1 与 3、1 与 4，行末计数 3。字幕：仍然取输入 1，再与输入 3、输入 4 配对。这一行列出了三对：1 与 2、1 与 3、1 与 4。
3. **D09**：第 2 行加入 2 与 3、2 与 4，行末计数 2。字幕：轮到输入 2，只找比 2 更大的编号，所以检查 2 与 3、2 与 4。不要再回头检查 2 与 1，那与 1 与 2 是同一对。
4. **D10**：加入第 3、4 行及计数 1、0。字幕：输入 3 只与输入 4 配对。到了输入 4，没有更大编号，这一行没有新的一对。

## D-D 六次检查，零条结果

主场景：完整六对清单，逐对强调图中两条线段并显示对应纵坐标；已知：D03、D07–D10。密集页。

1. **D11**：当前行 $3+2+1+0=6$ 整体出现。字幕：逐行相加，三加二加一加零，一共检查六对。接下来逐对核对交集。
2. **D12**：依次强调 1 与 2、1 与 3、1 与 4，显示高度 0 与 1、0 与 2、0 与 3，分别标空。字幕：1 与 2、1 与 3、1 与 4 的纵坐标分别是 0 与 1、0 与 2、0 与 3，都不能同时成立，因此这三对交集为空。
3. **D13**：依次强调 2 与 3、2 与 4、3 与 4，高度 1 与 2、1 与 3、2 与 3，分别标空。字幕：剩下的 2 与 3、2 与 4、3 与 4，纵坐标也分别不同，所以交集同样为空。
4. **D14**：计数卡“检查 6 对／结果 0 条”。字幕：开场问题有答案了：这个逐对检查方法检查六对，最后没有结果。看图已经知道不相交，不会让这个方法跳过它规定要检查的输入对；其他方法能否少检查，是后面的问题。

## D-E 为什么不会漏掉一对？

主场景：先提问，再给任意编号的证明；已知：D07 的枚举规则。密集页。

1. **D15**：仅显示“不漏、不重，对更多输入也成立吗？”字幕：列出四份输入的六对，还不是一般证明。如果输入更多，只找更大编号为什么仍然不漏、不重？

思考窗口：D15 后静默 5 秒，后续证明行隐藏。随后同页累积。

2. **D16**：引入任意两份不同输入，定义较小编号 $i$、较大编号 $j$，完整条件 $i<j$。字幕：任取两份不同输入。它们的编号一定不同，把较小的编号叫作 i，较大的叫作 j，因此 i 小于 j。这里不是指定某一对，而是在讨论任意一对。
3. **D17**：显示“第 i 行包含所有更大编号 → 包含 j”。字幕：处理编号 i 那一行时，规则要求与所有更大编号配对，其中一定包括 j。因此这一对必定被检查到。理由不依赖位置，也不依赖它们是否相交，所以不会漏掉任何一对。

## D-F 为什么不会重复，也不会与自身配对？

主场景：第 i 行与第 j 行的方向示意。已知栏：D16 的 $i<j$、D07 的规则。密集页。

1. **D18**：显示“只能出现在较小编号 i 的行”。字幕：同一对只能出现在较小编号 i 那一行。到了较大编号 j 那一行，只允许找比 j 更大的编号，不会回头找 i。
2. **D19**：加入“第 i 行中，j 只出现一次”。字幕：而在编号 i 那一行，每个更大的编号只列一次，j 也只出现一次。所以这一对总共只检查一次，行内和行间都不会重复。
3. **D20**：加入“更大排除相同”。字幕：编号更大，也排除了相同编号，所以不会把输入与自身配对。这个证明适用于任意两份不同输入。

## D-G 基准方法正确性的条件

主场景：不漏／不重／单对求交正确三个条件，再接结果结论。已知：D05–D06、D17–D20。普通页。

1. **D21**：完整显示条件句。字幕：只要每次两线段求交得到的完整交集正确，枚举就会检查到所有相交输入对，并且每个相交输入对恰好留下一个结果。
2. **D22**：显示“后续算法的对照基准”。字幕：枚举证明不替代两线段求交本身的正确性证明。这是一个可以让后续算法对照的基准方法：先明确每对的交集，再保证每对都恰好检查一次。

## D-H 一共多少对：先数有顺序的选择

主场景：居中说明数量，再加入第一份／第二份两列选择；已知：上集 U08–U10 的输入身份。密集页。

1. **D23**：定义 $n$，写“原始输入的份数”。字幕：把原始输入的数量记作 n。四份输入时，n 等于 4。重合输入仍各算一份，n 不是图中不同位置的数量。
2. **D24**：条件 $n\ge2$ 与“暂时区分选择顺序”出现。字幕：先假设至少有两份输入。为了计数，我们暂时把先选谁、后选谁区分开；这是计数办法，不是把无序输入对改成有方向的结果。
3. **D25**：分别显示第一份 $n$ 种、第二份 $n-1$ 种。字幕：第一份有 $n$ 种选择。选定之后，第二份不能与第一份相同，所以有 $n-1$ 种选择。
4. **D26**：显示整行 $n(n-1)$。字幕：每一种第一份的选择，都对应 $n-1$ 种第二份的选择，因此有顺序的选择总数是 $n(n-1)$。

## D-I 每个无序对恰好数了两次

主场景：先选 1 后选 2、先选 2 后选 1 并列；已知栏：D24 的计数条件、D26 的乘积。密集页。

1. **D27**：两种顺序合入同一个无序对。字幕：同一个无序输入对被数了两次。例如先选 1 再选 2，和先选 2 再选 1。任意两份不同输入都恰好有这两种顺序，没有第三种。
2. **D28**：完整公式 $\dfrac{n(n-1)}{2}$ 出现，不逐字符揭示分母或结果。字幕：因此，把有顺序的选择总数除以 2，就得到无序输入对的数量，也就是 $\dfrac{n(n-1)}{2}$。
3. **D29**：公式下方加入“每个无序对检查一次”。字幕：前面已经证明基准方法恰好检查每个无序输入对一次，所以这个数也就是它的检查次数。

## D-J 代入四份输入逐行核对

主场景：等号对齐的三行，预留分式高度。已知栏：D28 公式、D23 的 $n=4$、D11 的枚举计数。密集页。

1. **D30**：整行 $\dfrac{4(4-1)}2=\dfrac{4\times3}2$。字幕：代入四份输入。先算四减一，得到三，分子变成四乘三。
2. **D31**：加入整行 $\dfrac{4\times3}2=\dfrac{12}2$。字幕：四乘三等于十二，所以现在是十二除以二。
3. **D32**：加入整行 $\dfrac{12}2=6$，再与六对枚举表对应。字幕：十二除以二等于六，与前面逐行列出的六对一致。公式没有替代枚举证明，而是数出了同一批输入对。

## D-K 不足两份输入

主场景：零张卡与一张卡，先给不可配对结论，再显示公式核对。已知：D23 数量含义、上集 U12。密集页。

1. **D33**：显示 $n=0$、$n=1$ 与“选不出两份不同输入”。字幕：没有输入，或者只有一份输入时，都选不出两份不同的输入，所以检查次数为零。这个结论直接来自可配对对象，不需要先套公式。
2. **D34**：完整显示 $0\times(0-1)/2=0$ 与 $1\times(1-1)/2=0$。字幕：代入公式也都得到零。零份输入时出现的负一只是代数表达式的一部分，不能解释成有负一种选择；前面的选择计数推导限定在至少两份输入时。

## D-L 输入增多，检查数增长

主场景：三行表，每行在本段对应句开始前完整显示。已知：D28–D29。密集页。

1. **D35**：$10\times9/2=45$，再揭示 $100\times99/2=4950$。字幕：十份输入需要检查四十五对。一百份输入，需要检查四千九百五十对。
2. **D36**：加入 $1000\times999/2=499500$，再标“即使全部不相交”。字幕：一千份输入需要检查四十九万九千五百对。即使全部互不相交，逐对检查方法也照样检查这些对，最后却没有结果。检查对数和相交对数是两个不同的数量。

## D-M 输出本身也需要工作

主场景：同尺度分栏身份卡表示 n 份相同非零线段，不能用挪开线段模拟不同几何；具体公共线段先介绍。已知：上集 U47–U48、D23、D28。普通页。

1. **D37**：新例子“n 份输入，每份均为 $(0,0)$ 到 $(4,0)$”。字幕：另一方面，让 n 份输入都占据从 $(0,0)$ 到 $(4,0)$ 的同一条非零长度线段。每一对都会相交，交集都是这条完整线段，输入身份仍然不同。
2. **D38**：显示结果数 $\dfrac{n(n-1)}2$，输入对记录逐条示意。字幕：此时结果条数也等于 $\dfrac{n(n-1)}{2}$。如果要求逐条列出这些结果，任何方法都不能省去输出它们本身的工作。几何上只有一段，不代表只需输出一条记录。

## D-N 检查次数不是完整运行时间

主场景：并列三项“几何判断与计算／保存结果／精确数值运算”，各项随解释揭示。已知：D06、D36、D38。普通页。

1. **D39**：三项依次完整出现，最后显示“本章只数检查对数”。字幕：还要区分检查次数和实际耗时。每次检查内部要做几何判断和计算，保存结果也要工作。使用精确分数时，数字越长，算术运算也可能越费力。因此本章只计算要检查多少对，不把一次检查说成固定的实际耗时；完整工作量分析留到后续章节。

## D-O 闭环与下一章

主场景：回到四条互不相交线段与“检查 6 对／结果 0 条”，然后只显示下一章问题。已知：D14、D21、D29。普通页。

1. **D40**：回顾卡先显示，问题再出现，均有对应讲解。字幕：回到开场，四条互不相交线段，逐对方法检查六对，结果为零。我们已有不漏、不重的基准方法，但它总要检查所有无序输入对。能不能利用位置关系，少检查一些对，同时仍然找全结果？下一章《扫描线为什么只需关注邻居》将从明确的简化条件出发研究这个问题。
