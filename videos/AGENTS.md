# 视频工程规则

适用于本目录及所有子目录。

通用制作规则以本文件为准；各工程 README 保留具体命令、文件映射、教学内容和当前验收状态，并引用本文件，避免重复维护。下文“默认制作配置”允许具体项目显式记录覆盖值；该覆盖不适用于禁止渲染、禁止调速等硬性约束，也不构成执行渲染的授权。

## 视频渲染

- 禁止助手渲染或导出视频，包括整片和片段。
- 不得以修改、验证、验收或交付为由，直接或通过脚本、工具、子代理间接执行视频渲染或导出。

## 默认制作配置

- 默认输出为 3840×2160、60 fps，不抽帧。Remotion 工程默认保留 1920×1080 逻辑排版，以 2 倍渲染比例直接栅格化为 4K；换算已有帧率数据时，保持原始播放时长、动画时序和音频速度。
- 默认采用 H.265 硬件编码、`yuv420p` 像素格式、无损 PNG 中间帧及 AAC 192 kbps 音频。硬件加速设为 `required`，不可用时直接报错，不静默回退到软件编码；macOS 使用 VideoToolbox。
- 默认视频码率为 `null`，不指定 CRF 或目标视频码率，保留 FFmpeg／硬件编码器默认行为及默认预设；不要将用于 H.264 的 `setX264Preset` 套用于 H.265。实际画质、文件大小和速度需通过成片验证。
- 默认并发数为 4，用于控制 4K 页面和 PNG 缓冲的内存占用；该值不是经基准测试确认的最快配置。
- 默认使用 Azure 音色 `zh-CN-Xiaoxiao:DragonHDFlashLatestNeural`。项目显式覆盖后，以该项目确认的音色为准；环境变量不得静默改变已选音色，失败时不得改换音色或回退到系统语音。

## 工程与运行环境

- 每个视频工程的源码、配音素材和生成工具须自包含，不依赖相邻视频工程；已有配音素材应能直接用于制作，无须再次调用语音服务。
- 仅使用已安装的依赖、运行时和浏览器；缺少组件时停止依赖它的操作，告知用户安装方式，等待用户安装完成并明确通知，不自动安装。
- JavaScript／TypeScript 工程使用 pnpm；运行脚本或 CLI 时使用 `pnpm --config.verify-deps-before-run=false run …` 或 `pnpm --config.verify-deps-before-run=false exec …`，关闭运行前自动安装依赖。
- 浏览器检查默认使用已有 Chrome、无头模式及系统分配的临时端口，结束后关闭自身启动的进程。可见窗口须遵循单独授权要求。
- 输出目录中被 Git 忽略的产物不得强制暂存。

## 口语稿与读音

- 字幕和语音合成输入分开维护，通过稳定的镜头 ID 对应。生成脚本只读取独立口语稿，不以字幕原文兜底；修改字幕后同步核对口语稿。
- 数学口语稿应明确区分横纵坐标，用口语表达乘法、负数和下标，并明确分隔列举的字母。
- 读音标注只作用于指定片段，不全局替换词语，不改变字幕；拼接普通文本与标注文本后必须保留完整口语稿。
- 采用 `text`／`pinyin` 读音对象时，对象仅含这两个字段；`text` 为无标点的连续汉字，每字对应一个小写拼音音节，单个空格分隔，以 `1`–`5` 标声调（轻声为 `5`，ü 写作 `v`）。标点和字母保留在普通字符串中，不在口语稿内直接输入 SSML、语速字段或带声调符号的拼音。
- Azure 中文读音标注转换为 `sapi` 音素，例如 `chong2 he2` 转为 `<phoneme alphabet="sapi" ph="chong 2 he 2">重合</phoneme>`；普通文本始终 XML 转义。格式依据 [Azure 中文音素文档](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/speech-ssml-phonetic-sets#zh-cn)。服务拒绝请求时停止，不丢弃标注后重试。
- 合成前提供不请求服务、不写音频或时长数据的 `--dry-run`，执行完整文案校验并展示实际音色、完整口语稿和 SSML。格式、字段或字数错误须在请求前定位到镜头与片段；格式校验不代表语境读音正确。

## 音频与时间线

- 原样保存语音服务返回的音频；FFmpeg 可检查解码，ffprobe 可测量时长，不借这些步骤调整音频速度。
- 待本次生成的全部目标片段通过检查后，再替换正式素材与时间数据；音频按镜头 ID 命名，保持口语稿、素材和时长数据可对应。
- 时间线以实测音频时长加明确的停顿安排构建；动画和提示映射到镜头实际时长，不让音频迁就旧时间窗。静默镜头和思考窗口须显式维护。

## 音频速率

- 绝对禁止调整音频速率，包括语音合成请求中的语速参数、音频后处理中的加速或减速，以及播放器或渲染器中的倍速设置。
- 保留语音服务返回的原始音频及原始语速；不得通过重采样、时间拉伸或其他间接方式改变播放速度。
- 画面与音频不匹配时，调整镜头时长和时间线以适配原始音频，不得为了迁就分镜时间窗而调整音频速率。

## 坐标图比例

- 所有二维坐标图默认采用等比例坐标：X、Y 轴每个单位占用相同的屏幕长度，使用相同的网格刻度间隔，形成正方形网格。绘图区本身可以是长方形。
- 优先保持现有绘图区大小，通过扩展坐标显示范围适配，不裁掉教学所需的点、线或标注，并检查标签是否重叠、越界。不要分别拉伸两轴来填满画面。
- 若横纵数值跨度悬殊，等比例确实影响教学可读性，允许制作时对具体画面显式指定不等比例并记录原因，同时在画面中清楚标明“不等比例示意”；不得由程序根据数据自动切换。
- 此规则适用于开场及正文所有二维坐标图，一维独立数轴不涉及横纵比例比较。

## 教学排版与布局检查

- 教学分组与对齐语义显式维护，不从全角空格、中文或标点猜测分组；题目、独立判断和结论与连续等式推导使用各自适合的对齐方式。
- 逐步揭示的未来步骤须预留完整空间，隐藏状态不得改变对齐宽度或行高；含分式的分组须预留足够行高。
- 布局检查使用生产排版组件和完整页面内容，覆盖开场及正文，检测列宽和正文高度超限。
- 失败页须报告并继续检查其余页面，整体以非零退出码结束；不得通过自动缩字号、拆页或丢弃内容隐藏失败。用户执行的导出入口应先执行同一检查，失败即停止导出。

## 验收边界

- 文案校验、音频解码、时长检查与布局检查各自只证明对应检查通过，不能替代读音、画面内容或音画同步验收。
- 发布或关闭任务前，须按该视频的权威规格检查真实成片，完整试听中文可懂性、坐标、字母、公式、自然度与同步，并核对思考窗口。
- 无头检查或渲染结果不代表可见桌面验收通过。助手不得为补齐验收执行视频渲染；尚未完成的试听、成片或可见桌面验收须如实记录。
