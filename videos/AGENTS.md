# 视频工程规则

适用于本目录及所有子目录。

本文件保留贯穿视频全部工作阶段的约束；特定工作所需的规则和操作说明通过下文链接读取。同一要求只在所属章节完整定义，其他章节引用并补充该阶段的检查动作，不重复维护要求全文。共享命令与模板归工程操作说明；各工程 README 保留项目差异、专用命令与文件映射、教学内容和当前验收状态，并链接对应公共章节。不得将部分工程的能力或当前状态推广为所有工程共有。“默认制作配置”允许具体项目显式记录覆盖值；该覆盖不适用于禁止渲染、禁止调速、唯一浏览器等硬性约束，也不构成执行渲染的授权。

## 工作依据与推进

- 开始、恢复、修复或交付视频工作时，读取[制作、修复与交接](../docs/agents/videos/workflow.md)，核对当前阶段、已确认依据、修改范围及未解决问题。已有内容、读音、画面或配置没有问题时保持原样；不能把可选优化升级为必改项，也不能重新打开无新反证的既定结论。
- 已确认样例是扩展全片的实际基准，不能仅声称“已参考”或“复用组件”。按[参考继承与代表样例](../docs/agents/videos/new-video.md)对应到本集的教学对象、操作和呈现行为，并提供相应检查证据；已有有效确认不重复索取。

## 教学内容呈现

- 规划、制作、修改或审校教学内容、分镜、画面与口播前，读取[教学呈现规则](../docs/agents/videos/presentation.md)，落实区域职责、内容引入、历史依据、音画对应与可视化选择。
- 教学内容的调查、前置知识引用及禁止重复要求，遵循[教学内容复用与禁止重复规则](../docs/agents/teaching-content-reuse.md)。
- 涉及语义动画、高亮或内容切换时，读取[时间线规则](../docs/agents/videos/timeline.md#教学内容与提示的生命周期)；涉及画面数学显示及颜色时，读取[数学排版与教学染色](../docs/agents/videos/typography.md)。

## 视频渲染

- 禁止助手渲染或导出视频，包括整片和片段。
- 不得以修改、验证、验收或交付为由，直接或通过脚本、工具、子代理间接执行视频渲染或导出。
- 导出前的音频检查、分类计数及提供导出命令的条件，必须遵循[导出前音频检查](../docs/agents/videos/operations.md#导出前音频检查)。

## 音频速率

- 绝对禁止调整音频速率，包括语音合成请求中的语速参数、音频后处理中的加速或减速，以及播放器或渲染器中的倍速设置。
- 保留语音服务返回的原始音频及原始语速；不得通过重采样、时间拉伸或其他间接方式改变播放速度。
- 画面与音频不匹配时，调整镜头时长和时间线以适配原始音频，不得为了迁就分镜时间窗而调整音频速率。

## 工程与运行环境

- `shared/ui/LessonPage.tsx` 已退役并删除，禁止恢复、复制或重新导入旧组件。说明与推导页统一复用 `MathLessonPage` 和 `TeachingMathLines`，不得按是否含 LaTeX 切换页面布局；普通文字仍按文本排版，数学内容使用 LaTeX。专用几何过程页面保留其有教学依据的布局。
- 所有视频工程（包括新建工程）的 ESLint 配置必须接入 `shared/checks/component-policy.ts`，禁止覆盖或关闭旧组件禁用规则。共享源码检查使用同一策略。

- 视频工程的浏览器自动化、布局检查及 Remotion 视频、静帧、纯音频导出，只能使用当前 Remotion 版本对应的 Chrome Headless Shell；普通 Chrome 的无头模式不等价。准备命令或执行相关操作前必须读取并满足[唯一浏览器约束](../docs/agents/videos/configuration.md#唯一浏览器约束)。本条也适用于仅向用户提供命令的情况，不授权助手执行渲染或导出。
- 每个视频工程独立维护教学内容、配音素材与制作入口，可以依赖仓库内 `shared/` 公共基础模块，不依赖相邻视频工程。公共模块不得导入具体视频的内容；已有配音素材应能直接用于制作，无须再次调用语音服务。单集目录不要求脱离仓库运行。
- 仅使用已安装的依赖、运行时和浏览器；缺少组件时停止依赖它的操作，告知用户安装方式，等待用户安装完成并明确通知，不自动安装。
- JavaScript／TypeScript 工程使用 pnpm；运行脚本或 CLI 时使用 `pnpm --config.verify-deps-before-run=false run …` 或 `pnpm --config.verify-deps-before-run=false exec …`，关闭运行前自动安装依赖。
- 输出目录中被 Git 忽略的产物不得强制暂存。

## 验收声明边界

- 文案校验、音频解码、时长检查与布局检查各自只证明对应检查通过，不能替代读音、画面内容或音画同步验收。
- 检查数量、覆盖完成或命令退出成功不等于所有问题已解决。完成声明须匹配当前版本、实际覆盖与未解决事项；按[验收证据](../docs/agents/videos/delivery.md#检查目标与完成证据)核对，不能以笼统的“全部通过”代替。
- 无头检查或渲染结果不代表可见桌面验收通过。助手不得为补齐验收执行视频渲染；尚未完成的试听、成片或可见桌面验收须如实记录。

## 按工作读取

同时涉及多项工作时，在相关操作前一并读取并遵循对应规则。

- 创建工程、调整制作配置、音色或准备用户导出时，读取[视频制作配置](../docs/agents/videos/configuration.md)。
- 生成、修改或交付封面时，读取[视频封面规则](../docs/agents/videos/covers.md)。
- 开始新视频、制作代表样例或扩展到全片时，读取[参考继承与代表样例规则](../docs/agents/videos/new-video.md)。
- 编写、修改或审校字幕与口播稿，合成、修正或检查配音时，读取[配音与字幕制作规则](../docs/agents/videos/narration.md)。首次全文制作或明确要求全文审校时，另读[全文审校流程](../docs/agents/videos/narration-review.md)；指定字词或句子的局部微调不进入该流程。
- 生成或替换音频素材、编排或检查音画同步、静默窗口与页末停留时，读取[音频与页面时间线规则](../docs/agents/videos/timeline.md)。
- 制作、修改或检查坐标图、教学页面与字幕排版时，读取[图示与排版规则](../docs/agents/videos/layout.md)。
- 运行工程命令、启动预览或浏览器检查、生成配音、准备用户导出命令或查找发布素材时，读取[工程操作说明](../docs/agents/videos/operations.md)，仅使用其中明确适用于当前工程的入口。提供导出命令必须遵循其中的[模板约束](../docs/agents/videos/operations.md#必须按模板提供命令)及[五阶段命令模板](../docs/agents/videos/operations.md#五阶段命令模板)，禁止临时拼写绕过模板与核验；模板缺失或不适用时先处理缺口。
- 整理单集工程文件、最终收尾、检查或交付内容与素材、报告配音修正结果、验收成片、发布或关闭任务前，读取[交付与成片验收规则](../docs/agents/videos/delivery.md)，落实其中的[工程整洁门禁](../docs/agents/videos/delivery.md#完工时的工程整洁门禁)。
