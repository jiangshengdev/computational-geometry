# 剪切如何改变坐标

第一集规格为 [CNB #203](https://cnb.cool/jiangshengdev/computational-geometry/-/issues/203)，制作任务为 #204–#208。参考直线方程教程的制作方式，遵循 [视频工程规则](../AGENTS.md)。

## 当前状态

已实现 56 个镜头、16 个完整教学页面和对应的 Azure 原速配音。整集入口为 `ShearIntuition`；`Shear204`、`Shear205`、`Shear206`、`Shear207` 为独立片段入口，`LayoutCheck` 复用生产页面检查内容容纳与标签重叠。

实测音频驱动时间线为 23039 帧，60 fps 下约 **6 分 23.98 秒**。每页最后一段配音结束后，普通页保留 3 秒；负高度计算、逆变换、新纵轴刻度三个推导密集页保留 5 秒，在 `src/storyboard.ts` 显式标记。停留期间保留完整公式与最后一句字幕，页内镜头仍保留原来的 0.4 秒间隔。`204-12` 和 `207-01` 的问题音频结束后仍各有 240 帧思考窗口，答案在后续镜头出现。音频时长向上取整到整帧，每段前有 12 帧引入；不改变原始音频或播放速度。

教学顺序：扫描线与竖直线段动机 → 正纵坐标点移动 → 负高度思考题 → 固定点的直角／斜坐标读数对照 → 完整逆变换 → 从 (2,0) 推广到新横轴不变 → 新纵轴刻度逐步推导 → 第二次思考与两种操作同屏对照 → 下一集引子。示意不是算法执行轨迹。

## 环境与命令

本次检查使用 Node.js 24.17.0、pnpm 11.8.0，以及已安装的 FFmpeg、ffprobe、Chrome 和 Playwright CLI 0.1.22。工具入口直接执行 TypeScript，要求 Node.js 22.18+（22.x）或 24+，具体范围见 `package.json`；不支持 Node.js 20。锁文件为 `pnpm-lock.yaml`。安装、Studio 预览、lint 和打包见公共[基础命令](../../docs/agents/videos/operations.md#基础命令)；`build` 产物已忽略。

配音 dry-run、内容与布局检查见公共[内容与布局检查](../../docs/agents/videos/operations.md#内容与布局检查)。本工程的必要回归入口为：

```sh
pnpm --config.verify-deps-before-run=false exec node --test scripts/speech-timing.test.ts scripts/azure-alignment.test.ts
```

配音环境和失败续跑见公共[配音环境与续跑](../../docs/agents/videos/operations.md#配音环境与续跑)。本工程采用默认音色，按需生成某个片段：

```sh
pnpm --config.verify-deps-before-run=false run video:narration --issue=204
```

也可用 `--shots=204-10,206-03,206-04,206-16` 仅生成指定镜头；镜头 ID 必须存在且不能重复，不可与 `--issue` 同用。上述四段的口播将字母 `y` 写作 `why`，字幕和公式仍保留 `y`；其他字母和既有中文拼音标注不变。

不传 `--issue` 或 `--shots` 会生成全部配音。生成器完整校验镜头 ID、读音对象及讲解锚点，在本次目标音频全部解码、时长与字词边界校验成功后发布素材；续跑仍执行这些检查。

如果合成服务返回零时长的朗读词，生成器保留原 MP3，并调用 Azure 发音评估，以口语稿为参考取得该音频的逐词对齐时间。仅补充缺失时间及解决边界冲突所需的相邻词；不同分词方式保留服务返回的完整词，不拆分或均摊时长。采用的对齐词必须无错误标记，全文须完整匹配且无遗漏／插入，时间须有效且不重叠；不涉及的词保留已有合成时间，不因发音评分而改动。失败就停止，不插值或估算词时长，也不重新合成来替代已确认音频。对齐数据绑定音频 SHA-256，`audio-timing.json` 的 `alignment` 保留原始合成边界及服务响应，`words` 为字幕和动画共用的有效边界。内容检查同时核对哈希和响应；标点可为零时长，朗读词不可。自动对齐属于模型测量，不能替代实际同步试听验收。

本工程布局检查的 `--screenshots` 将关键生产页面截图写入系统临时目录，供人工检查。

## 字幕、读音与教学时序

- 字幕采用参考教程的 40px、顶部分隔线与数学混排；按 Azure 字词时间切短句，合并短引导语。当前共 130 条字幕。同一教学页内静默保留上一句，换页重置；两次思考期间保留问题字幕。
- 全部 56 段口语稿已做文本核查，其中 48 段含局部读音对象，覆盖横、乘、撇、平行、长度、朝、量等语境。未标注片段交给 Azure 依语境合成；文本核查和服务成功不代表读音试听通过。
- 数学公式、轴名、点名、坐标和刻度均使用 KaTeX；中文保留中文字体。坐标轴正方向、读数辅助线及位移路线有箭头。重合横轴合并标注 x、x′。
- 图形运动和公式揭示使用口语片段锚点对应的实测时间。开场扫描线连续推进；先回顾直角坐标读数，再读斜坐标。新纵轴的坐标总结到推导完成才显示；结尾用同屏两图对照。
