# 统一缩放与坐标范围

分数坐标怎么变整数？一步步找出坐标的范围｜剪切变换③

规格：[CNB #215](https://cnb.cool/jiangshengdev/computational-geometry/-/issues/215)。遵循 [视频工程规则](../AGENTS.md)。用户于 2026-10-23 明确确认 [#216 代表样例](https://cnb.cool/jiangshengdev/computational-geometry/-/issues/216)通过，并授权继续 #217–#219；该确认不代替后续整集试听和成片验收。

## 整集内容与入口

全片 `ShearIntegerCoordinates` 按顺序组织 19 页、72 段口播，60 fps、32015 帧，时长约 533.58 秒（8 分 53.58 秒）。`Shear216` 保留已确认的 8 页、28 段样例；`Shear217` 单独检查坐标范围部分，`Shear218` 单独检查系数与结尾部分。所有入口复用同一套生产组件及实测时间线。

| 部分 | 页面        | 教学内容                                                              |
| ---- | ----------- | --------------------------------------------------------------------- |
| #216 | 8 页、28 段 | 有理数、公共分母、统一缩放、端点计算、第一次练习、几何放大与视野调整  |
| #217 | 4 页、15 段 | 数轴上的绝对值、第二次练习、全部端点参与求 M、加入 1 的原因、两轴范围 |
| #218 | 7 页、29 段 | 下标、系数取法、a 与 b 的逐步计算、数轴距离上界、实例与一般结论、结尾 |

第二次练习先给出整数端点和求最大值的方法，保留 4 秒静默后，逐步揭晓 `max(1,3,4,2,1)=4`。绝对值用数轴上的距离解释；范围页用等比例坐标方框表示 `−4≤X,Y≤4`。

系数部分先解释下标及乘法，再使用 `a=Y₂−Y₁`、`b=X₁−X₂` 逐行算出 `a=b=5`。数轴展示 `M−(−M)=2M`，说明交换减法次序不改变绝对值；实例的实际值 5 不超过上界 8。`c=aX₁+bY₁` 只用于说明系数为整数，不推出 `|c|≤2M`。结尾区分本次系数取法与方程整体倍乘后的系数，并提醒交点仍可能是分数。

新增数轴页复用 `NumberLine.tsx`，二维图继续复用 `Diagram.tsx` 的同一等比例投影。`coefficient-storyboard.ts` 只组织系数部分的分镜数据，不另建时间线或排版实现。

## 样例内容

Studio composition `Shear216` 包含 8 页、28 段独立口播，60 fps、11371 帧，时长约 189.52 秒：分数坐标开场、正整数公共分母、两个方向使用同一倍数、P 的逐步计算、Q 的 4 秒练习与答案、固定单位长度的真实放大、放大后的视野调整。

例子为 P=(1/2,-2/3)、Q=(-1/3,1/6)，D=6，整数端点分别为 (3,-4)、(-2,1)。两轴始终等比例。绘图区扩展至 600×600 逻辑像素，利用左栏下方空间。初始两轴标出 −1、1，绘图区范围为 [-1.2,1.2]，为端点留出边距。几何放大阶段每单位固定为 250 逻辑像素，数学坐标乘 6；超出视野的端点以同色方向箭头及文字提示，线段按绘图区裁切。放大开始后保留透明度为 0.4 的原始端点与原始线段作为对照，它们始终使用原坐标和当前视野投影。之后单独拉远视野，每单位逐渐缩至 62.5 逻辑像素，两轴范围扩大到 [-4.8,4.8]，完整显示整数端点及标签。原点、绘图区大小与数学坐标在视野调整时保持不变；拉远后网格仍按单位绘制，数字刻度每 2 单位标注。所有点使用同一个倍数，因此线段形状保持、长度变为原来的 6 倍。

## 使用

Node.js ^22.18.0 或 >=24，Remotion 4.0.538。基础预览和打包入口见公共[操作说明](../../docs/agents/videos/operations.md#基础命令)。在 Studio 选择 `ShearIntegerCoordinates` 查看整集，或选择任务编号检查对应片段。生产页面必须有全部实测音频数据，不使用估计时长兜底。

在本工程目录运行：

```sh
pnpm --config.verify-deps-before-run=false run video:dev
pnpm --config.verify-deps-before-run=false run video:lint
pnpm --config.verify-deps-before-run=false run video:narration --dry-run
pnpm --config.verify-deps-before-run=false run video:check-content --decode
pnpm --config.verify-deps-before-run=false run video:check-layout --screenshots
```

配音环境要求与原速规则见公共[配音环境](../../docs/agents/videos/operations.md#配音环境与续跑)。`video:narration` 调用 Azure；`--dry-run` 只检查并打印实际输入。失败保留暂存目录，使用日志中的 `--resume=<目录>` 续跑；也支持 `--shots=<镜头ID>`。全部目标通过后才发布到 `public/narration/`、`src/audio-timing.json` 与 `src/captions.json`。生成脚本不读取字幕作为朗读兜底。

`video:check-layout` 使用系统临时端口、已有 Chrome 与 Playwright CLI，在无头浏览器检查生产组件。`--screenshots` 保存浏览器页面截图，不导出视频或 Remotion 静帧。

口播支持原有字符串与 `{text,pinyin}` 局部标注；新增的 `{letter:"M"}` 表示显式英文 IPA 字母读音。它不修改普通字符串的解释方式，因此已确认样例的 28 段 SSML 指纹保持不变。`--dry-run` 还复用字幕生成器的分句校验，在请求服务前发现字幕与口播的分句数量不一致。读音是否自然仍须试听实际整句。

### 用户自行导出

工程和素材检查通过后，用户可在本工程目录自行执行：

```sh
pnpm --config.verify-deps-before-run=false run video:export
```

入口仅生成并保留 `out/shear-integer-coordinates-frames/` 的 PNG。先按[公共预检说明](../../docs/agents/videos/operations.md#用户导出)设置 `REMOTION_BROWSER_EXECUTABLE`，按需独立运行 `pnpm --config.verify-deps-before-run=false run video:preflight`。是否已经预检由人类判断；导出只核验自身运行条件，不读取预检记录或状态，也不重复内容和布局检查。4K、60 fps、并发 4 保持不变；后续分阶段使用 H.265 硬件编码，并与同时间线 PCM 音轨封装为 MOV。该入口由用户运行；助手未执行视频渲染或导出。
