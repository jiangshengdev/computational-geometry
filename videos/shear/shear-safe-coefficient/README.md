# 从事件间距到安全系数

剪切系数为什么有五次方？一步步推导那个带 256 的公式｜剪切变换⑤

制作与验收遵循 [视频工程规则](../../AGENTS.md)，权威规格为 [#231](https://cnb.cool/jiangshengdev/computational-geometry/-/issues/231)。用户在报告样例问题已修复后明确要求“继续实现”，本轮据此通过样例扩展门禁，实施 #233–#235；这不替代新增配音或真实成片验收，也未修改 CNB 状态。

默认 composition `ShearSafeCoefficient` 按顺序播放全片 18 页、66 段。`Shear232` 保留六页样例；`Shear233` 包含三种间隔变化、高度差界、展开横坐标差、五次方来源和等号思考题；`Shear234` 包含最终系数、最大缩短量核验、保序证明及精确验算。各入口使用同一套正式素材和实测时间线。

配音入口复用公共制作流程，`--resume=<日志给出的临时目录>` 只复用音色、完整 SSML、格式与音频哈希一致的片段。`video:captions` 依据正式实测时间重建字幕。整句音频需独立试听，文本、解码与对齐通过不能替代试听。当前未接入全片导出命令。

旧版“所需条件不在当前画面”“覆盖上一步”“跨页丢失前式”不作为继承目标。样例的自动检查独立列出规格所需公式，并检查生产 DOM 中实际可见的 KaTeX 内容；不是只断言依赖栏存在。

样例六页按首次讲解的位置组织内容：前集或本集此前已经讲清楚的内容可直接作为辅助依据；新对象、条件和结论先在主场景随讲解逐步出现，本页保留，换页后才进入辅助区。分子页先介绍从输入端点与实际交点中选取的 P、Q，再介绍分数表示、整数与正分母条件；通分、非零分子与距离下界在同一主场景累积。辅助区不提前展示本页才引入的对象或才推出的结论。具体分数例子及倒数思考题中的 2<6 也在主场景首次呈现。

回顾页的正文块整体水平居中、块内左对齐。分子页介绍对象时同样居中，在右列第一步推导出现前的半秒平滑左移，并在该步出现时到位；移动沿用绝对时间线，跨音频片段连续，不改变字号、公式顺序或原音频时间。

当前讲解行先完整显示，再开始口播；整行等式及其结果保持完整，不拆成逐字或逐项出现。逐行显示通常比对应口播提前 0.2 秒，片段开头受音频起点限制时从音频起点显示，仍早于首个发音。这里的“逐步”指教学行之间的推进，不要求同一行的结果等口播推导完才显示。232-02 口头定义 q；232-07 先介绍选取的 P、Q，再解释 X_P、X_Q 与横坐标分数的对应关系。画面重要新内容与口头解释双向核对，标题、旧内容保留及预告不要求逐字朗读。

## 内容与验收入口

来源：[事件间距与剪切系数](../../../docs-site/docs/segment-intersection/shear/order.mdx)。

| 推理段   | 内容核对                                                                   |
| -------- | -------------------------------------------------------------------------- |
| 回顾     | M 的定义、M≥1、输入整数坐标、约分后正分母界、剪切公式                      |
| 具体分数 | 实际距离 1/6；分母不超过 3 保证下界 1/9；不声称取到                        |
| 分子     | p、r 整数；q、t 正整数；通分；横坐标不同推出分子非零；绝对值至少 1         |
| 分母乘积 | 保留上一段距离下界；分别乘正数；8×8 与平方相乘解释四次方                   |
| 倒数     | 保留正数条件及乘积上界；题目和 2<6 在无旁白 4 秒内保留；答案稍后揭示       |
| 连接     | 保留具体条件及两段所用结论；逐行追加完整间距不等式；下界不等于真实最小间距 |

检查覆盖步骤揭示前后、字幕切换、每页首尾、页末停留和思考窗口。工程检查、整句试听、真实成片与可见桌面验收分开记录。助手不渲染或导出视频，不据工程检查关闭任务。

新增内容由 `src/continuation.ts` 维护教学行与独立字幕文案；`src/ShearDiagram.tsx` 维护本集专用图示。三种变化用 `s=1/2` 的等比例示意，明确标注“示意，非最终系数”；最终系数仅用精确分数验算。两处思考窗口分别为 `232-13` 和 `233-24`，各在音频结束后静默 4 秒再揭晓。新增页均保留 5 秒页末回看。

| 新增推理段 | 画面与口播对应                                                         |
| ---------- | ---------------------------------------------------------------------- |
| 三种变化   | 先介绍示意坐标与系数，再给新横坐标和间隔，逐行累积                     |
| 高度界     | 端点范围、线段内点范围、纵坐标定义、最高减最低；排除任意延长线交点     |
| 新横坐标差 | 先讲 P 在 Q 左边及 s>0，再代入、去括号、合并同类项，解释原间隔与变化量 |
| 五次方     | 最大缩短量 2Ms、同除正数 2M、乘倒数、64×2 与 M⁴×M；等号反例            |
| 最终系数   | 正分母比较、倒数反向、两处余量、同乘正数与约分                         |
| 闭合证明   | 变化量不小于负绝对值、代入间距及高度界、严格大于零                     |
| 精确算例   | M=3、两个精确分数、同乘正分母乘积、31104<262144                        |
