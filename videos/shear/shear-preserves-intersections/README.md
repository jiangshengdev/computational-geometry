# 不丢交点，不添交点

制作与验收遵循 [视频工程规则](../../AGENTS.md)，依据父规格 [#241](https://cnb.cool/jiangshengdev/computational-geometry/-/issues/241)。2026-10-26，用户确认当前代表样例已经满足，并要求继续后续工作；该确认解除 [#242](https://cnb.cool/jiangshengdev/computational-geometry/-/issues/242) 的扩展门禁，后续按 #243、#244、#245 推进。确认对象是 `e865d1e` 的十一页、三十五段样例，不代表新增全片已经验收。

获确认时的原样例时间线为 24177 帧、402.95 秒（60 fps）。后续加入整条线段对应、逆变换、双向证明、完整重叠区间、特殊情况及开场总结，并在口播审校后重生成受影响音频；当前版本及验收边界见下方“当前验证收尾”。缺失素材时入口明确报错，不使用估计时长或空白声音代替。

全片入口为 `ShearPreservesIntersections`；`Shear242`、`Shear243`、`Shear244` 是同一内容与正式音频的分段入口，时间线按片段选择重新从零起算。新增教学内容在 `src/continuation.ts`；页面、字幕、数学排版和音频仍走原有共享实现。交集专用图示在 `src/IntersectionDiagram.tsx`，两条输入与完整公共部分共用同一个剪切参数，反向演示亦同步还原；浮点屏幕坐标只用于绘图，证明依据是一般代数式。
